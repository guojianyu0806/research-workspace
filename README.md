# 研序 Research Workspace

面向第九届传智杯AI大模型创新应用挑战赛的科研助手。以可追溯原文为基础，提供论文管理、阅读翻译、问答写作、发现追踪、引用图谱与数据绘图工作台。

| --- | --- | --- |

各本地账号分别保存文献、研究任务、数据集、订阅和偏好。默认空间仍可直接使用。页面中的模型配置入口只允许默认空间操作，账号空间继承进程内的模型服务配置。

## 在当前Windows环境运行

依赖已按授权安装到项目 `.venv`，无需重复安装。在项目目录执行：

```powershell
.\scripts\start.ps1
```

打开 [本地工作台](http://127.0.0.1:8765)。其他端口可用 `.\scripts\start.ps1 -Port 8766`。若脚本执行策略拦截，可用：

```powershell
.\.venv\Scripts\python.exe -m uvicorn research_workspace.api:app --host 127.0.0.1 --port 8765 --workers 1
```

保持终端运行，按Ctrl+C停止主服务及其子进程；关网页不会停止服务。不要对同一数据目录重复启动服务或增加Uvicorn工作进程。服务仍仅绑定127.0.0.1，未做公网部署验收。

新机器使用Python 3.12建立虚拟环境，再安装 `requirements-dev.txt` 并执行 `pip check`。仅运行应用可使用 `requirements.txt`。当前机器不依赖系统默认的 `python` 命令。

需要本地语义检索时，安装 `requirements-semantic.txt`（含基础依赖、FastEmbed 0.9.0），显式运行 `.\.venv\Scripts\python.exe scripts\prepare_semantic_model.py` 下载模型。`requirements-semantic-lock.txt` 留存本次实际依赖版本。模型为英文 BAAI/bge-small-en-v1.5、384维，项目内文件约67MB；这不是运行内存指标。下载需要网络，应用运行期只从项目目录校验、离线加载模型，启动不会隐式下载。首次构建语料向量较慢，后续按固定解析版本缓存。

## DeepSeek设置

在右上角选择「模型设置」，输入自己在DeepSeek开放平台创建的API密钥。接口地址已固定为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`，也可选择 `deepseek-v4-pro`；这些名称依据2026年10月8日查阅的[DeepSeek官方说明](https://api-docs.deepseek.com/)。

保存只更新当前服务进程及研究工作进程的配置，不验证远端、不产生模型请求。密钥不会写入项目文件、Git或响应；重启主服务后需要重新输入。创建问答、翻译或写作任务时，会将选定原文或输入文本发往该服务，并可能产生费用。模型输出需通过结构及原文引句校验；这不等于对结论准确性作保证。

在途或排队任务存在时暂不能更换模型。取消在下一次调用前生效，正在执行的调用可能仍完成；已成功返回的结果会保留。工作进程中断后，在途研究任务标记为「调用中断，结果未知」，需明确重试，不自动重复可能已计费的调用。

中文问题检索英文资料或数学符号未命中时，可先执行一次小型检索词扩展调用（至多512输出token），再检索真实原文并回答。查询词、是否扩展及来源版本保留在结果记录中；扩展失败降级为原问题检索。向量模型准备好后，与BM25采用RRF融合；生成词组及向量分数均不充当事实证据。结果中的 `retrieval.semantic` 记录实际启用、缓存或降级状态。英文向量模型的中文问题依靠双语扩展辅助，不宣称中文原生语义能力。

## 新增功能入口

页头的 **演示示例** 提供 Transformer、BERT、RAG 三篇固定版本真实论文的阅读入口、七个研究任务输入及论文实验数据绘图。示例任务只预填文献和问题，点击创建后才调用实际模型；示例中不预置模拟研究结果。BLEU 数据转录自 Transformer v7 第8页表2，是原论文报告值，不是本项目复现实验。

本机默认空间已准备示例。换到独立账号后，示例入口会按该空间的 PDF 指纹检查就绪状态；缺失资料可通过卡片的官方 PDF 链接获取并导入。新环境可先启动服务，再运行 `.\.venv\Scripts\python.exe scripts\prepare_demo.py`；该脚本只导入本机默认空间，按内容复用已有文件及数据集，保留已编辑的元数据，不恢复归档文件。来源和演示步骤见 [真实示例指南](docs/demo-examples.txt)。

- 文献管理 → **版面结构**：选择物理页码后点击分析，查看表格、图像位置、作者机构与公式候选，点击出处定位，或下载该页结构JSON。复杂公式保留原文，不猜测LaTeX。
- 文献管理 → **参考文献筛选**：输入主题词，查看排序理由与正文引用；可恢复被筛出的条目。明确选中并点击检索后才查询公开书目，最多选5条，不自动下载。
- 发现与追踪 → **下载、解析并回答问题**：在选定论文卡片填写问题，一个任务保存下载、解析和固定版本问答的检查点；取消或失败保留已完成阶段。仅处理这篇明确选择的论文。
- 发现与追踪 → **核验代码关联**：从元数据、原PDF前12页正文及链接取代码线索，只读核对公开GitHub仓库的README回指、支持的许可证与源码；新鲜且相关的核验结果可获得推荐加分。实际GitHub接口本轮连接失败，仍保留“未核验”；未运行代码或实验。
- 问答与写作 → **文献翻译/学术文本翻译**：可选“统一术语”，每行使用`perplexity => 困惑度`格式；任务冻结词表，保护代码、公式、日期、数字和源文本。已有译文不自动改写，修改词表应新建任务。
- 研究任务详情 → **模型用量与执行记录**：展示实际请求、服务商输入/输出Token、回执覆盖、阶段、未知结果与公开价格估算区间。价格快照为2026-10-17，[来源](https://api-docs.deepseek.com/quick_start/pricing/)，金额为USD估算而非实际扣费，旧调用及未报告用量不补算。
- 数据与图表 → **三维分层雷达图**：3至12行表示指标，2至6个数值列表示系列层。原始数值须在0至1，或勾选按指标行归一化；常数指标映射为0.5。可调整角度并保留独立图表，导出原始值、坐标及转换记录。

## 配置与数据

应用读取进程环境变量；`.env.example`是模板，**不自动加载 `.env` 文件**。也可由自己的本地启动环境提供模型配置，避免把密钥写入命令历史或仓库。

| 环境变量 | 含义 |
| --- | --- |
| `RESEARCH_DATA_DIR` | 数据目录，默认项目 `data/`；自定义时使用绝对路径 |
| `RESEARCH_MAX_UPLOAD_MB` | PDF上限，默认50 MiB，范围1至200 |
| `RESEARCH_MODEL_BASE_URL` | 兼容chat/completions的模型地址 |
| `RESEARCH_MODEL` | 模型名称 |
| `RESEARCH_MODEL_API_KEY` | 模型密钥，建议用页面临时输入 |
| `RESEARCH_OCR_ENABLED` | `auto`（默认）、`1`或`0` |
| `RESEARCH_OCR_TESSDATA` | OCR语言数据目录 |
| `RESEARCH_OCR_LANG` | OCR语言；启动脚本发现本项目已授权语言数据后使用`eng+chi_sim` |
| `RESEARCH_SEMANTIC_ENABLED` | `1`/`0`或`auto`；启动脚本发现本地模型清单后启用 |

当前语言文件位于 `data/ocr/tessdata`，仅保存在项目目录，不随Git提交。OCR通过现有PyMuPDF执行，没有安装系统OCR程序。直接执行Uvicorn而不运行启动脚本时，需要自行设置OCR环境变量。

原始PDF保存到各空间的 `originals/`；SQLite存储文献、解析结果、任务、CSV和图表规范。账号空间位于 `data/spaces/`，账号库和会话在 `accounts.sqlite3`；发现数据在各空间 `discovery.sqlite3`，本地向量缓存分别存于各空间 `semantic.sqlite3`。模型切换及任务状态不改变历史PDF与原文证据。

备份前停止主服务和子进程，再将完整数据目录复制到新的位置；不能只复制数据库主文件而遗漏WAL。恢复时保留现有目录，指向或恢复完整备份。Git仅保存源代码，不备份论文、数据库和生成结果。

`/api/health`分别报告解析进程与活动进程存活。异常退出没有自动故障拉起；必要时查看数据目录中的worker.log并重启服务。
