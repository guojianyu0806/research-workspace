# 研序 Research Workspace

面向第九届传智杯AI大模型创新应用挑战赛的科研助手项目。以论文原文和可定位证据为基础，逐步实现解析、问答、阅读翻译、检索推荐、引用图谱与学术写作。

## 当前阶段

2026年10月8日启动开发。当前建立工程和过程管理基线，后续功能按独立步骤开发、验证并提交。尚未完成六大比赛模块，官方测试资料包尚未取得。

第一条开发流程：上传PDF → 后台解析 → 文献与页面查看 → 检索原文 → 点击证据定位。当前没有配置商业模型，也不把本地原文检索标记为大模型问答。

## 技术方向

- Python 3.12、FastAPI提供应用接口，后台逐页处理PDF。
- PyMuPDF提取文字、原页坐标与页面图像，SQLite保存处理版本、任务和证据。
- 浏览器原生模块构建首阶段工作台，不依赖外部CDN。
- 运行数据、上传论文和测试产物留在忽略目录，不纳入源代码提交。

依赖版本依据2026年10月8日PyPI公开元数据固定；安装与运行结果另行验证。项目依赖安装在本目录 `.venv` 中，不修改系统Python环境。
