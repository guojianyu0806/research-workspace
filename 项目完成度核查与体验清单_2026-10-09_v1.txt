三、第一轮体验清单

以下“预期”是应检查的行为，不表示本次已经替用户完成了这些真实体验。记录时在每项后写：通过 / 失败 / 部分通过 / 未测。
第一轮优先做 T01—T15、T25、T28；联网发现、综述与长文档可在基本读写流程确认后进行。

[ ] T01　入口、账号与模型配置
操作：按第二节顺序配置模型并登录，依次打开六个模块。
预期：没有白屏或无限加载；新账号显示自己的空间；未配置模型时明确提示，不能显示伪造结果。

[ ] T02　批量上传与独立失败
操作：同批上传两份有效PDF，可另加一份无效PDF作为失败样例。
预期：每份有状态；坏文件报错时，好文件仍入库并解析；页面能看见进度和总页数。

[ ] T03　完全重复文件
操作：将同一PDF另存为不同文件名后再次上传，保持文件内容不变。
预期：识别为完全重复，不新增一份相同文献。此项不能证明语义去重已完成。

[ ] T04　论文版本与两侧差异
操作：先上传v7，再上传v1；到“文献管理→资料与版本”检查候选，点“比较正文”，再选择保留或指定优先版本。
预期：两个原文件保持可追溯，两侧出处可打开；选择明确生效。当前没有上传时的冲突弹窗或可靠的新旧版本警告，不要等待不存在的入口。

[ ] T05　阅读、缩放与原文搜索
操作：打开公式/表格页，切换缩放和页码；使用原文中的准确词，如 attention 或 normalization 搜索；点击结果。
预期：回到正确文献和页面，框选位置随缩放保持对应。阅读栏是字面关键词搜索，中文意译搜不到英文属于当前范围限制。

[ ] T06　元数据与归档恢复
操作：编辑标题/作者，刷新后检查；归档，再到管理页恢复。
预期：修改持久保存，归档后常用列表隐藏，恢复后重新出现。当前归档不等于删除文件。

[ ] T07　细粒度结构与JSON
操作：“文献管理→版面结构”分别分析首页、表格页、公式页；检查作者机构候选、表格值、图片位置和公式；下载本页JSON。
预期：内容能定位回原页；未支持公式保留原文并标记复核；JSON里的文献、解析版本和页码正确。不要只看候选名称，必须和原页比对。

[ ] T08　标题树和引用双向导航
操作：“文献管理→标题与引用”点章节；展开一条多次被引用的书目，逐处定位正文，再从正文引用列表回到书目。
预期：标题、书目和正文位置对应。当前入口在管理页，原PDF图像里的引用标记不能直接点击；作者年份型引用尚未可靠支持。

[ ] T09　单篇细节问答与引用
操作：“问答与写作→文献问答”，选一篇已解析论文。依次问：
  “作者分别隶属哪些机构？逐一给出原文依据；未明确列出的信息请说明未找到。”
  “文中的β₁、β₂用于什么，取值是多少？请引用原文，不要用常识补充。”
  “使用了什么GPU、多少张？报告的BLEU对应什么数据集和实验设置？”
预期：回答事实与原页一致，数字和条件完整；每个关键结论有对应依据。文中没有该项时，说明缺口是正确表现，不预设标准答案。

[ ] T10　证据不足与引用版本
操作：问一个确定不在所选论文中的问题，如“作者在2026年新增实验的实测成绩是多少”；再打开一条旧答案的出处，之后切换优先论文版本或重新解析，再打开旧出处。
预期：不编造不存在的实验；旧答案仍定位其原文献及原解析记录。引句确实存在，还要人工判断它是否真正支持回答。

[ ] T11　多篇比较
操作：选择两篇不同论文，问“按LayerNorm位置、参数量、上下文长度逐项比较；未找到的信息明确标注，不同实验设置分别说明”。如需旧版本，勾选“同时显示非活动版本”。
预期：每篇都有各自依据；不能把不同实验条件直接并列为同一比较。当前没有专用对比表组件，可能以分段文字呈现。

[ ] T12　局部翻译
操作：“文献管理→本页文字”中，在同一文本块内选一句，再点“翻译所选文字”；另试跨块选择。
预期：送去翻译的原文与所选片段一致；跨块选择提示重新选择。当前不是在PDF图像上划词，也没有悬停即译。

[ ] T13　指定页翻译和双向联动
操作：“问答与写作→文献翻译”，先翻译一页；在完成结果中分别滚动原文栏和译文栏。
预期：对应文本块联动，长短译文不应逐渐错位；点出处回到原页。两栏是原文/译文文本，不是原位排版PDF对照。

[ ] T14　整篇翻译与导出
操作：用短论文翻译整篇可用文本，导出任务与来源的Markdown；核对首部、中部、末尾。
预期：没有静默只译前几页；缺失页单独报告，已完成块保留；导出能查看原文、译文和来源。当前没有原位翻译PDF或独立HTML导出。

[ ] T15　中译英与内容保护
操作：选“学术文本翻译”，目标英语，输入含术语、代码、公式、数字、单位和引用的短段落。例如：
  “本研究计划比较两种归一化位置。训练批量设为32，学习率为0.001。公式为 $y=x+2$，代码为 `loss = model(x)`，参考文献标记为[1]。上述内容是实验计划，尚无实测结果。”
预期：学术英文通顺；数字、可识别代码公式、引用不变；计划不能被翻成已经完成的实验。单位和跨段术语仍需人工逐项核对。

[ ] T16　研究任务取消、保留和重试
操作：创建短的多块翻译任务，观察进度，取消，再检查已保存部分；遇真实失败时点重试。
预期：取消后不再启动下一次调用；正在执行的调用可能仍结束。已完成的块保留，重试不无条件重做所有块。文献翻译的单个长块内部若失败，当前块可能重做；不要假定任意片段均已有检查点。

[ ] T17　按论文名检索、下载与入库
操作：“发现与追踪”搜索准确论文名或arXiv编号，检查题名与版本后点“下载原文入库”。
预期：显示来源、检索时间和状态；下载成功才进入统一解析，只有元数据时不能全文问答。若超时，记录报错与查询词。本轮没有确认外网成功，上次真实检查曾超时。

[ ] T18　参考文献筛选与检索
操作：“文献管理→参考文献筛选”输入主题词，查看排序依据，恢复被筛出的书目；选1—2条点检索。
预期：书目不被删除，查询理由可解释；结果区分标识相符、标题候选和版本差异。该页目前不能直接下载候选，也不能自由粘贴整份书目列表；需转“发现与追踪”检索后入库。

[ ] T19　订阅与重复检查
操作：“发现与追踪”建立一项订阅，点立即检查，再次检查，并查看记录。
预期：状态、时间和失败说明清楚，同一更新不重复计为新结果；缓存内可能得到旧返回。“立即检查”目前不保证绕过24小时缓存。服务未运行时不会检查更新。

[ ] T20　推荐和点赞/踩
操作：文献库和公开元数据已有内容后，刷新推荐，对一条点喜欢/不喜欢，离开页面再回来。
预期：偏好保留，参与推荐评分与排序；不保证每点一次都发生可见换序。GitHub链接当前只是未核验线索，不应显示为已复现成功。

[ ] T21　引用图谱

预期：A→B表示A引用B；图中依据能回到原文，排名明确是局域PageRank。两个同一论文版本之间没有引用边可能完全正常；不能因主题相似而强行连线。

[ ] T22　专题综述
操作：选择多篇，输入“围绕归一化位置与训练稳定性，总结共同点、差异和局限，每个主要判断给出处”。
预期：有共同主题和差异分析，而非逐篇摘要拼接；论点与来源一致。它使用有限检索片段，不能默认已通读全部论文。

[ ] T23　未来方向

预期：能看到原文生成与公开摘要核验两个阶段、查询词/时间、保留/暂移出方向及证据不足说明。没有后续全文确认，不能把“暂移出”解释为已解决，也不能把没搜到解释为确定创新。

四、已知未完成及后续处理优先级

优先补齐影响主流程的缺口：
G01 双栏顺序接入主解析与翻译；混合扫描页OCR；复杂公式、无边框表与扫描结构。
G02 解析历史列表、解析取消、单页重试的页面入口；摘要的独立展示。
G03 完整参考书目字段及论文框架Markdown的References章节。
G04 原文引句是否真正支持答案、数字/实验设置是否准确、真实翻译质量与术语一致性。需要真实模型案例和人工标准答案。
G05 论文名/书目检索下载、订阅和未来方向的真实联网验证。书目检索页尚缺候选直接下载和自由输入整份列表。

明确的功能或验收差距：
G06 目前只有归档恢复，无删除；版本冲突没有上传时提示，语义去重仍是标识/文本片段相似度规则。
G07 逐token生成流未实现；任务页采用状态轮询，答案完成后显示。后端任务状态SSE不能算回答token流。
G08 GitHub仅为摘要/评论中的未验证链接，无代码关联核验或代码优先加权；推荐主要使用已缓存元数据与词匹配。
G09 订阅每次仅取有限最新结果，尚缺完整分页/水位追踪；24小时缓存可能限制短周期和立即检查的实际新鲜度。
G10 未来方向仅有限arXiv摘要筛查，缺后续全文确认及严格相对时间筛选；20篇以上真实论文图谱尚未验收。
G11 CSV图注缺趋势分析；架构图不保证自动产出；向量语义检索、语义去重效果评估待做。没有统一Token/费用统计及端到端费用上限。
G12 文献翻译以文本块为检查点；长块内部调用失败的部分结果可能需重做。原位翻译PDF、HTML导出、悬停翻译未实现，当前已选择Markdown与文本块交互路径。
