# 真实页面 v5 极简合成工具

工具为 `scripts/compose_real_ui_demo_v5.py`。只读取已有录屏、剪映原生配音和普通 ASS 字幕，不录屏、不调用模型或语音服务、不制作卡片动画。默认仅检查，只有明确传入 `--render` 才会导出新文件。旧合成器和旧成品均保留。

## 输入清单最小示例

以下是后续实际录制完成后填写的格式示例，路径为待替换项，不表示文件已经存在：

```json
{
  "version": 1,
  "final_name": "研序_真实页面演示_剪映配音_v5.mp4",
  "subtitles": "artifacts/video-real-ui-v5/captions.ass",
  "segments": [
    {
      "id": "S01_A",
      "source": "artifacts/video-real-ui-v5/takes/real-page-take1.mp4",
      "start": 5,
      "duration": 20,
      "speed": 1,
      "narration": {
        "source": "artifacts/video-real-ui-v5/voice/S01-native-1x.wav",
        "source_start": 0,
        "offset": 0.5,
        "native_speed": 1,
        "provider": "剪映原生",
        "evidence": "artifacts/video-real-ui-v5/voice/native-settings-evidence.json"
      },
      "evidence_note": "填写真实录屏时间、页面及任务编号，不记录密钥。"
    }
  ]
}
```

- 相对路径以本项目根目录为准，绝对路径也可用于明确的本次素材；输出目录及检查报告必须位于项目中。
- `source/start/duration` 是录屏源文件、入点秒数、取用秒数。每段时长须落在 1/30 秒帧格上；不限于固定镜头数，也不强制 380 或 400 秒。
- `speed` 只能为 1；省略时也为 1。未知滤镜、速度、循环或补帧字段会被拒绝。
- `narration.source` 是真实原生配音。`source_start` 是音源入点，`offset` 是该旁白在本段中的进入时间。默认使用从音源入点至文件末尾的全部声音；确需取用部分音源时可显式填写 `duration`。
- 音频必须完整放入所选真实视频段落。超过段落时长即报错，需选更长录屏或调整剪辑，不会拉慢声音或冻结画面。
- `native_speed:1` 与 `provider:"剪映原生"` 是制作者声明。工具不会鉴定供应商或原生语速；须在 `evidence` 对应的本轮设置证据中人工核对。旧版原生 0.8 配音不能只改声明复用。
- 无旁白的操作段可写 `narration:null`；正式导出至少需要一段实际配音。字幕可写 `null`；提供时须是 1920×1080 的 ASS，不接受动画字幕命令。
- 计划没有整段旁白跨片段的特殊机制；若需要一条旁白跨多个录屏切口，可按实际音源时间填写相应的 `source_start` 与 `duration`，保持声音顺序和 1 倍速。

## 只检查现有真实旧素材

从本项目根目录执行：

```powershell
.venv\Scripts\python.exe scripts\compose_real_ui_demo_v5.py docs\submission\video-real-ui-20261030-v5\check-only-existing-footage.json --check-only
```

该例只检查已有 `full-workflow-take9.mp4` 中的 5 秒选段，不生成音频或视频，不作为 v5 已录制的证明。输出包含媒体实测信息、输入 SHA-256、选择范围与总帧数。`ffprobe` 验证视频流、帧数、帧率和格式，可排除单帧或图片格式；它不能证明画面内容没有伪造，仍须核对录制来源和实际画面。

可选保存检查报告，目标文件须尚不存在：

```powershell
.venv\Scripts\python.exe scripts\compose_real_ui_demo_v5.py artifacts\video-real-ui-v5\edit-plan.json --check-only --report artifacts\video-real-ui-v5\input-check-v1.json
```

## 实际素材就绪后导出

```powershell
.venv\Scripts\python.exe scripts\compose_real_ui_demo_v5.py artifacts\video-real-ui-v5\edit-plan.json --render --output-dir artifacts\video-real-ui-v5\final-v5-r1
```

输出目录必须尚不存在；失败残留也不覆盖。需要重试时另指定新目录。

处理步骤为：以 1 倍速截取真实视频 → 等比缩放并补黑边至 1920×1080、统一 30fps → 拼接 → 按真实时间放入原生旁白 → 可选普通字幕 → 导出 MP4。音频仅进行取用、采样率归一和时间放置，不使用 `atempo` 或任何语速调整；没有卡片、解释动画、冻结、循环和光流补帧。

目录中保留分段文件、FFmpeg 日志、已验证清单、最终 MP4 和 `final-manifest.json`。工具核验分辨率、帧率、帧数、音视频时长及全片完整解码，记录输入输出 SHA-256。人工试听和视觉检查初始状态均为未完成，不能将工具通过表述为引用核对或内容验收通过。

## 本轮工具验证范围

本工具只用历史真实连续录屏执行 `--check-only`，并执行 Python 语法检查。没有通过本次工具验证生成演示视频、假画面或测试配音。实际 v5 录制、原生 1 倍速新配音与最终合成另行留证。
