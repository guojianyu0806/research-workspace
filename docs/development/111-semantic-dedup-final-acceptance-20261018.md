# 文献语义去重、原文与历史引用保留验收

## 实际交付

本轮完成保守语义去重的本地扫描、逐对身份核对、人工确认、保持分开、撤销、审核历史和JSON导出。确认只设置版本关系与常用版本，不删除、覆盖或重定向两份PDF及历史引用。主库只运行扫描，没有应用分组操作。

提交链：`874e084`增加扫描与事务审核；`28f39a7`修复授权声明抽样并报告不完整范围；`c3ddbb3`接入页面并修复跨文献高亮；`d840d85`补齐常用列表折叠与历史版本展开。110是实施阶段记录，保留原样。

## 判断与操作边界

三处正文抽样使用已有本地英文向量，不安装或下载新模型。向量只发现候选；主要正文使用五词指纹对比，书目不提供论文自身身份。自身arXiv标签限定第一页明确页眉/页边标签，文件名只作辅助；文件名与正文冲突也不得确认分组。

- 完整可读、正文不少于200个词项、自身标识一致且正文指纹重合不低于0.35，才能成为需要人工核对的同一论文候选。
- 完整可读主要正文在只归一空白后完全一致，也可成为需人工核对的副本候选。大小写和Unicode字符保留；图片、未知OCR及数学语义并未证明相同。
- 仅主题相似、标识不同/冲突、正文过短或只有部分可读内容时，去重入口禁止分组。已有版本组也不跨组传递配对结论。原有版本入口会拒绝已验证的身份冲突，包含待合并组的其他成员。
- 确认时在写事务中重新读取来源和资格，旧扫描遇到解析、元数据或分组变化会拒绝。撤销保留原审核与旧关系；发生后续版本组变更时拒绝覆盖后续选择。

界面位于“文献管理→语义去重”。默认扫描当前文献与文献库，也可扫描全库；选择常用左/右侧前展示两份文件的具体影响。确认后，阅读侧栏折叠非常用版本，可“显示历史版本”展开；通过旧引用打开的版本仍保留当前阅读位置并标为历史版本。资料管理下拉列表仍能访问两份文件。

扫描限60篇、每篇25万字符、总计300万字符及显示120对候选。超限、未读取、部分可读、没有合适语义抽样和向量未启用均明确报告，不冒充全库完整完成。没有自动合并策略。

## 发现与修复

真实首轮实验有两个不同论文低于向量候选阈值而未进入候选表，检查脚本的固定取值假设导致中断；报告随后显式保留不同自身标识的拒绝配对，首轮中断记录保留。

页面核对发现一处抽样落在授权声明，已提高正文段落长度要求并排除授权、版权和致谢片段。同一对Transformer v1/v7的修复后向量相似度约0.960、正文重合约0.720；BERT与Transformer v1相似度仍约0.875，但独立标识使其保持分开。不能把相似度当作论文身份或概率。

原页独立检查发现，阅读区当前文献检索模式清理旧结果时，会清掉跨文献/解析跳转刚设置的高亮。已先清理旧结果，再应用新引用的bbox。旧失败记录中的空高亮不计为通过；修复后两侧标识、正文抽样及历史解析共4处坐标分别重新核对通过。

确认分组后后台检索已折叠非常用版本，但侧栏仍平铺两份文件，已补齐实际折叠、历史展开和当前旧引用的可见性。六份独立验收文献确认后显示5份常用、1份可展开历史，撤销后恢复6份。
