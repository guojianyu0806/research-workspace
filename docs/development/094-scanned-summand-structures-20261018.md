# 复杂扫描求和项的结构与失败观察

新增`raster-summands-v1`，将被求和项与实际求和符号、各自上下限关联，分别保留位置与审核。该结果是求和子表达式，不能冒充完整等式。单页额外OCR上限160次，最多4个求和项；不调用模型。

有限支持单字符上下标、带平方的闭括号、基线减号、相邻方括号与文字片段。小字号曲线和数字片段仅按实际像素相接关系分组，不填充缺失墨迹；微小点可在目标脚标自己的x范围内保留。观察存在冲突时，保留原始读取和额外局部读取，不根据变量名称或常见损失函数补字。只有两次局部希腊文观察一致时，才使用对应字符；字体粗细不由OCR推断。

新增的求和测试与递归结构测试共14项聚焦检查通过，覆盖明确标注的派生ASCII平方误差求和、真实教材两条复杂求和的部分结构、擦除第一上限或整个被求和项后不能从相邻行补齐，以及0/90度源定位与原件不可变。

**真实原页仍未完整恢复。** 教材物理第33页第一项可保留`x_i`、`y_i`和闭括号平方；第二项可保留部分希腊变量下标、`y_i`和平方。其余小字号希腊字符、标点或变量观察仍有冲突，两项均输出未完成状态。审核保留所有成功/失败观察。擦除整个被求和项时，记录实际符号右侧的空白搜索区，不能把下一个公式当作当前被求和项。

用于正向恢复完整`sum_{i=1}^{I}(x_i-y_i)^2`的样例是派生夹具：从真实原页保留求和及变量像素，删除指定内容并平移原页尾项后整体栅格化。它不代表原论文存在该排列，也不作为真实原页全式验收通过的证据。夹具构造与实际解析分离，解析器只读取图像。
