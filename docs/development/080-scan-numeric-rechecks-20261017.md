# 扫描数值的局部原图复核

在已有本地引擎上增加明确的分块/稀疏文字分割模式。稀疏识别仅替换空间上一一对应的数值观察，保留其遗漏的孤立数字；不按相邻数值、参考答案或模型常识补小数点。已修复稀疏模式单独使用会遗漏 `2 / 4 / 8` 的问题。

针对数值中的 `] / I / l / O` 等易混字形，从其原页字词区域生成 288、432 DPI 的独立二值视图；两次无字符白名单的 OCR 一致且为完整数字时才输出新的候选。原始识别、两次输出、处理参数、裁图范围和解析版本锚点同时保留。对包含开括号的表达式不执行此修正；预算耗尽或不一致时保留旧值。每页额外复核最多 24 次。

两处错误“=”来自表格边线或空白，其字词框甚至超出了单元格。复核时在真实单元格内部裁切，仅排除该内部裁图为空白的符号；真实有墨迹的等号保留。所有排除均有原识别及对应裁图记录。
