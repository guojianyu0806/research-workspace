# 管理区超大页原文预览本地验收

日期：2026年10月20日。产品修复版本：`da245cb`。本记录是121方案S5/G的增量验收，不是整项完成声明，不涉及Pro、外部验收、部署或参赛材料。

## 问题与修复

原管理区缩略图固定使用0.5倍、放大窗固定使用1.5倍。冻结派生样本中3200×4000页面的放大窗、12000×16000页面的缩略图均超出1600万像素的资源上限，导致预览失败。极端40000×50000页在最小0.25倍也超限，旧提示不能说明永久资源限制。

`manage.js`现在按照已保存的物理页面尺寸，在首选倍率及1、0.5、0.25中选择不超过首选值且满足资源限制的倍率。普通页沿用原首选倍率，CSS缩放不额外扩大光栅。没有可用倍率的页面说明安全限制并保留正文和原PDF，不显示无效的循环重试；网络失败仍允许显式重试。页面缓存版本同步更新。

## 冻结资料与运行边界

使用139阶段已经冻结的`tests/fixtures/book_reading/20261020-v1`原生旋转和大尺寸派生PDF。派生件来自公开教材原页，不冒称外部实际扫描件，也不将几何通过解释为公式、图表或翻译正确。

实际测试运行于动态回环端口、独立合成账号和新建的数据副本，没有登录用户账号或重启8765实例。浏览器仅允许访问本轮本机服务。所有文献、解析、物理页、文本块行及原PDF在测试前后计算摘要；没有调用模型。
