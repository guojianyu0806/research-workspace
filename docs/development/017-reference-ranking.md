# 可恢复的参考文献筛选与显式检索

日期：2026-10-09。对应 M4 参考文献列表检索、相关性筛选与身份核对。

新增 ReferenceDiscovery，基于指定解析版本的数字型书目及可核对的引用上下文排序。评分明确显示书目词命中、正文上下文词命中、封顶引用次数及方法/实验词线索。评分表达当前查询与本篇论文的使用关系，不评价客观学术价值；未命中条目仅从当前视图筛出，可恢复或继续选择，原文书目不被删除。

只有显式选择检索时才向既有arXiv发现服务发送书目标识或保守提取的标题片段，不发送父论文正文上下文。每次有明确调用预算；重复查询复用本次结果，沿用共享网络间隔、24小时缓存和有界重试。返回来源、时间、缓存、失败或预算跳过状态。标识一致、标题候选、未确认、标识冲突和arXiv版本差异分别呈现，不自动下载和替换本地文献。

验证：21项新增离线测试及既有发现/结构测试合计43项通过。包含真实Library的旧版本书目、MockTransport模拟的arXiv id_list协议、缓存来源时间、调用预算、错误脱敏、身份冲突、私有正文未传输和未下载PDF。上述协议测试没有实际联网，不代表当前arXiv服务可达或检索质量。

数字型书目的漏检、作者年份型引用、复杂书目标题提取和对学术相关性的语义判断仍需后续改进。新增 reference_discovery.py、test_reference_discovery.py 和本记录；既有论文与日期化资料均保留。UI/API接入另行记录。
