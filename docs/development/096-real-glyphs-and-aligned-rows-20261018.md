# 真实扫描希腊字符、求和项及对齐续行修复

本阶段使用项目现有教材和本地语言数据，不读取PDF原生文本作为扫描解析输入，不调用模型、不下载新依赖。

## 实现范围

- 在粗采样区域周围最多1点范围内按576 DPI源像素复核字符边界。逗号尾部允许2点范围，并要求候选源墨迹与原区域相交；没有填充或绘制缺失笔画。
- 希腊字符使用固定432/576 DPI、170/210阈值观察，每次必须有一对一致的希腊字形。保留英文原始冲突和失败的希腊观察。多块互相分离的墨迹不能被当作单字符读取，避免吞掉逗号。
- 同页字形参照要求：目标本身的OCR中已实际出现该字母；参照字母有至少两次独立观察；宽高比相近，灰度余弦相似度至少0.9，两种阈值的墨迹IoU均至少0.66。参照纠正不能继续成为参照，空白和异形不接受。两处原文位置与相似度均进入审核。
- 标点使用两个阈值的实际头部、下降尾部或紧凑点状墨迹核对。小脚标希腊字符单独按实际基线和有限脚标行读取，包括观察到的`t-1`，不根据常见公式补全。
- 对齐等号续行按两个水平墨迹、横向位置和行间距构造独立边界；跨越行边界的分式/操作数不会并入该行。候选不包含未经确认的初始表达式，不宣称推导语义等价，不生成完整多行LaTeX。

## 真实原页可复现结果

教材物理第33页：两条求和子表达式恢复为

```text
\sum_{i=1}^{I}(f[x_{i},\varphi]-y_{i})^{2}
\sum_{i=1}^{I}(\varphi_{0}+\varphi_{1}x_{i}-y_{i})^{2}.
```

物理第387页：恢复根号内分式子表达式

```text
\sqrt{\frac{\alpha_{t}}{\alpha_{t-1}}}
```

这些结果始终标记为需要人工核对的子表达式，不代表恢复了带左侧函数/等号及所有右侧项的整条等式。字体粗细也未由OCR确定。

物理第376页：识别2行和5行两组对齐续行，保留逐行原图、等号和可归属子观察；完整复杂推导仍未恢复，输出未完成。多行初始表达式及一般续行合并仍待实现。

## 验证和边界

26项聚焦测试通过，包括真实两条求和、希腊脚标、根号分式、擦除字符和等号、空白/异形不能借字形参照补写、源文献与保存解析不可变，以及90度页面的结果/审核/参照位置绑定。新增`verify_real_greek_scan.py`区分真实原页和擦除负例；原递归验收脚本更新为当前实际成功范围，历史验收产物保持原样。后续完整回归、API与浏览器验收另留记录。

后续页面检查发现重复求和下限中的`i=1`可能被错误组成对齐行，已要求续行等号左侧保留空白，并补充负例；对齐行模块5项检查通过。独立验收脚本同时修正了未知合并单元格的空位置处理和旋转后行组的展示顺序判断。失败记录保留，最终重新验收单独记录。

局部OCR一致及形状相似仍不是数学正确性的保证；当前只对现有资料逐例核对，不提供通用字符准确率。扫描表格误检、任意公式/矩阵和官方资料包仍未全部验收。
