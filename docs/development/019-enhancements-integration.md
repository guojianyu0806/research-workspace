# 版面、书目与三维图表的工作台接入

日期：2026-10-09。本阶段在既有工作台继续实现比赛清单中的功能缺口，不改写初始日期化规划。

文献管理增加“版面结构”和“参考文献筛选”标签。版面分析仅显式点击后执行，可按页导出JSON与定位原页；书目进入时只做本地排序，明确点击检索才查询公开元数据。切换文献、卸载组件或较旧请求晚到时，不覆盖当前页面。接口沿用账号空间解析，测试确认其他账号不能获取结构和书目，旧解析版本仍可明确读取，错误版本与超出预算请求被拒绝。

只读复查发现，读取归档文献资料的定位请求可能在用户切换文献后晚到，从而覆盖新导航。现为跨模块证据导航增加请求代号，并在模块切换、管理文献/标签切换、销毁及阅读翻页时使旧定位失效；晚到响应不能插入旧文献或触发阅读器跳转。

数据模块增加三维分层雷达图入口、相机角度与归一化说明。浏览器检查发现第一层标签可能与指标标签重叠，已移到各层外侧；变化只影响渲染标签位置。手机宽度下文献标签换行，结构区域与表格保持可访问。
