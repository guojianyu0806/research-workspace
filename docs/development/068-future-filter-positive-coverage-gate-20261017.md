# 正向实现与限制证据分离

第三轮 Pro 核对中，两条跨句实验条件的事实引句本身准确，但模型把“数据集不适用”的反向限制判为部分覆盖。该结果仍保留方向，没有误删；不过“部分实现”的分类含义不准确，因此不作为最终三类判定验收。

增加 `positive_requirement_satisfied`：只有原文明示的方法或实际结果正向满足至少部分原始要求，才能提升为部分覆盖；说明不可行、数据集定义、主题相关及反向限制都不满足此门槛。充分覆盖还需要全部原有范围、限定条件与联合审核门槛。旧版缺少该字段的记录不能用于新的自动筛除。

如已经获得准确且独立审核通过的部分结论或限制依据，保留该结论，不再对固定证据池做无必要的重复生成；被拒绝或没有有效引句的初判仍有一次补证和独立重审机会，所有检查点保留。模型服务内部可能为结构错误发起修复请求，实际 HTTP 次数逐次进入用量台账，不能把一个逻辑阶段等同于一次计费请求。

15 项专项回归通过。下一轮受控真实复测显式复用第三轮保存的条件、固定全文检索和未审核结论候选，全部支持度审核、必要补证、联合生成和联合审核重新执行。复用输入的旧调用账本和新审核调用分别记录，不冒充全链重新生成。

本阶段未进行部署、参赛提交材料或旧报告覆盖。
