# 流式输出的本机HTTP与浏览器联调

在独立数据目录、随机回环端口启动真实应用、后台任务和明确标注的模拟模型HTTP服务。模型服务只按输入证据返回固定内容，用于验证传输与引用审核衔接，不代表生成质量或Pro验收。测试代码在 `scripts/stream_fixture_server.py`、`scripts/model_stream_smoke.cjs`，不读取主库密钥，不接触实际模型服务。

17项HTTP与页面检查通过：生成结束前出现并持续增长的正文、草稿无引用操作/HTML执行、最终答案保留原文引句与解析版本、审核完成替换、用量回执、任务切换与页面往返、断流拒收与不自动重试、失败草稿不导出、取消关闭请求，以及760像素窄窗口和脚本错误检查。

成功产物：`artifacts/model-stream/2026-10-18T13-50-04-978Z/`，含页面截图、报告、HTTP回执及隔离测试数据。第一次实验因夹具问题中的中文触发额外双语检索调用，导致调用次数断言失败；已修正夹具故障标记，失败产物保留，未将其算作通过。

补充回归覆盖多篇比较、综述、框架、文献块翻译，以及虚构引句仍被拒绝；36项流式专项测试通过，9.57秒，见 `artifacts/model-stream-source-guard-final-20261018.xml`。按当前官方接口说明兼容结束分片同时携带正文/usage，以及usage-only分片；不累加中间累计用量。原文：https://api-docs.deepseek.com/api/create-chat-completion （2026-10-18核对）。

小分片实验发现逐分片查询取消状态会产生不必要的数据库读取，现合并为最多约每100ms检查一次，保留空闲等待取消；预览写入节流80ms。相同34项协议测试耗时从30.93秒降为9.60秒，此为本机协议实验，不是模型吞吐指标。另修复空任务列表刷新时未关闭旧事件连接的问题。
