# 阅读区本地语义检索实现

本轮接入已有的本地BAAI/bge-small-en-v1.5向量能力，不安装依赖、不下载模型，不调用Pro或其他付费服务。阅读区新增语义和混合检索；现有`/api/search`默认仍为字面匹配，调用方显式传入`mode`启用新路径。

检索在同一SQLite读快照中选择文献、完成的解析版本及原块正文，遵守归档和已确认优先版本。当前文献可显式固定历史`run_id`；运行中的重解析不能替换来源。排序器的文本和位置不直接用于显示，所有候选重新绑定原始块身份；错误文献/解析身份和不可信相似度会被拒绝。结果保留来源摘要、解析覆盖、原文、页码、bbox、排序渠道及搜索审核ID。

语义检索使用本地向量排序，混合检索将其与BM25通过RRF融合。参考文献标题和碎片按既有原文质量规则降权，明确的书目检索保留书目排序。相似度只是排序信号，不是正确率或事实核验。现有模型主要面向英文；允许用户补充英文检索词，不能假称已经实现通用中英跨语种检索。

每次最多12000个源块、800万原文字符、2个同时处理的请求。达到上限明确返回未完成，不默默缩小来源。语义不可用时混合检索明确降级为关键词；纯语义不伪装成关键词成功。超长块索引前5800字符的既有限制会显示覆盖警告。结果仍为完整原块，位置精度为文本块。

实施中相关核心回归92项通过；加入书目排序修复后，阅读检索14项专项测试通过。两者有重叠，不能相加。现有Starlette弃用警告保留；未新增依赖。首轮测试有一处测试代码使用不存在的方法名，修正后通过，旧失败日志保留。

真实本地向量、公开论文相关性与浏览器定位验收仍在执行，后续另存最终记录。首次实验的网络拦截误伤Windows asyncio本机socketpair，已改为只禁止外部连接；该失败实验不计通过。

本轮不进行部署或参赛材料。实时检索最新论文、全文核验和自动筛选方向的完整Pro流程继续待验收；本地检索测试不能替代其真实模型质量验收。旧PDF、历史报告和旧验收产物保留，源码按功能原位修改。
