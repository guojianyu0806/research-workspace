# 七条扫描推导续行的独立转写

新增`raster-row-geometry-v1`：在已观察的行边界内，以288 DPI源像素分别检测分数线、根号钩形/上横线、独立字符和下标。阈值下的连通墨迹、操作数范围和OCR观察都保留；字符框重叠不等于墨迹连通，仅合并包含在字形内部的小碎片和相邻的窄小断裂标点。

真实教材物理第376页的两组、共7条等号续行已逐条恢复转写候选。包括`alpha`的`t-1`下标、`beta`及其下伸笔画、两个独立根号相乘的分母、括号和末尾逗号。字符OCR只使用当前行自身的像素；大小写几何参照仅使用本行独立识别的数字及其实际位置，不从相邻行借字。432 DPI等比重采样与288 DPI源采样在审核中明确区分。

每行最多384次OCR、128个解析节点、7层递归；单页新增通道最多8行。未归属墨迹、未知字符、结构相交和语法不完整均阻止完整转写。新的观察与上一通道的失败树分别保存，不能用旧候选填补缺失字符。

行转写完成不等于整条推导的数学证明。结果使用`transcribed_aligned_continuations`，起始左式保持未确认，`mathematical_equivalence_verified=false`。每行有固定原文行号、自己的等号、位置和审核记录；旋转后的展示顺序不改变原文行号。

12项聚焦回归已通过，用时213.21秒，包括7行逐字转写、7个擦除负例、预算耗尽、0/90度不可变来源和版本绑定，以及原复杂推导回归更新。首轮11项检查有10项通过，90度测试曾按显示排序错误比对两组；已改用固定原文行号核对，失败日志保留，没有更改预期公式来消除差异。

日志另存于`artifacts/multiline-20261018-continue/focused.log`和`focused-fixed.log`。新增`scripts/verify_multiline_rows.py`分别验收真实栅格页、旋转页、删除beta和删除中间等号；更新原求和验收脚本以采用当前逐行恢复范围。全量回归、独立验收、API及界面结果将在后续记录中报告。
