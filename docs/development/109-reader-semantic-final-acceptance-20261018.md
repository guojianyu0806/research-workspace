# 阅读区语义检索与原文定位阶段验收

## 交付范围

本轮完成阅读区的本地语义检索、向量与关键词融合检索、历史来源固定及核对记录导出。复用已授权安装的FastEmbed与项目内BAAI/bge-small-en-v1.5文件，不新增依赖、模型下载或付费API调用。不是生成式问答功能。

提交链：`4d7255f`实现快照和检索服务，`58a873e`修复弱候选筛选并补充可审计术语别名，`82e0782`接入界面和复现脚本。108为实施中期记录，保持原样；本记录补充最终验收。

## 已实现行为

- 阅读区证据栏默认在当前文献检索，可切换到全部文献；提供混合、语义和字面三种模式。原有`/api/search`未传模式时仍为字面匹配。
- 混合模式将本地向量与BM25通过RRF融合；保留三条明确的英文术语替换规则并记录实际排序查询，例如missing words→masked tokens。它们只提供检索提示，不构造事实或改写引文。
- 可展开填写英文辅助词，填写后使用辅助词进行检索，原问题仍保留。现有英文向量不冒充通用中英跨语种能力，不会调用付费模型自动翻译。
- 所有文献、解析和源块在同一SQLite读快照中读取。归档和已确认优先版本生效，显式历史来源可复查；新解析完成不会替换已返回的来源。
- 返回完整原块、文献/解析/块ID、页码、bbox、源PDF摘要、快照摘要、排序渠道及审核ID。排序器提供的显示文本和坐标不直接信任，结果重新绑定原始快照。
- 点击候选在同一阅读区定位原页，保留检索问题和候选列表；文字预览折为六行，完整原块保存在导出记录及原文中。PDF高亮仍是块级定位，不声称逐字符定位。
- 切换论文、解析、范围或检索方式时清理失效结果，并忽略过期请求响应。可导出JSON核对记录，保留原问题、辅助词、实际排序查询、来源及位置。
- 两个同时处理名额、12000源块/800万字符预算及超长块前5800字符索引限制均明确报告。语义不可用时混合检索显式降级，纯语义不会冒充成功；空结果不代表全文不存在相关内容。

## 发现的问题及修复

真实首轮实验发现书目标题相似度过高，遮蔽词问题偏向背景说明，无关医学问题也返回约0.61相似度的候选。修复包括：应用既有正文质量权重降低书目/碎片排序；记录并使用有限的英文术语别名；语义候选最低余弦阈值由0.50提高为0.65。

阈值是本轮公开样例上的筛选设置，不是相关性保证、概率或事实审核。两个无关样例未返回候选，不代表所有无关问题都能排除。BM25或向量返回的条目仍只是需要用户核对的候选，不能自动形成研究结论。

首轮网络拦截脚本误伤Windows asyncio的本机socketpair，未完成向量验收；已改为只拒绝外部连接。首轮测试另有一处测试方法名错误，修正后重测。旧失败日志和22/24的真实首轮结果保留，不计为最终通过。
