# 未来方向的公开研究核验

日期：2026年10月8日。

Future Work任务拆成两个可保存步骤：先依据选定原文生成候选方向，保存结果并让出执行机会；再查询公开研究并核验摘要。取消或中断后复用已完成的生成与核验检查点，避免再次购买已有结果。每次检索和模型调用前检查取消状态。

每次最多进行3条arXiv关键词查询，每条读取5条按提交时间降序排列的记录。关键词来自方向标题、设想及参考文献标题中的英文术语；只有中文且无可用英文题名时明确为证据不足。这里没有跨语言检索或全面查新的质量保证，也未以时间降序冒充覆盖全部最新论文。

核验保留实际查询、检索/缓存时间、论文ID、官方链接、发表时间及公开摘要。模型判定必须引用对应检索范围内的真实来源和摘要原句；不匹配的ID、伪造引文、输出失败或连接失败均降级为证据不足，保留原候选。

返回分为「可能已有研究覆盖」「有限检索中未找到明确覆盖」「证据不足」。第一类仅暂时移出重点候选，仍需全文确认；未检索到不能证明新颖性或研究空白。原始生成章节与来源保留，新增核验记录独立标明 `future-verification-v1` Prompt版本。

独立核验模块32项离线测试通过，覆盖检索预算、来源ID与原句约束、错误降级、同步/异步取消。两阶段任务的检查点恢复和导出另有集成回归。所有模型输出均为测试模拟，未产生真实调用或质量指标。
