一、目标与实现
缩略图支持在当前文字页面放大核对，关闭后保持阅读上下文；显式进入原文阅读器时提供返回入口；章节目录定位对应提取文本。沿用现有视觉规范与共享框架，不改变顶层模块导航的尺寸和位置。

1. 点击原页缩略图打开模态预览，显示文献、页码及当前文本块的区域高亮。支持适合宽度、适合整页、150% 和 200% 缩放；放大后可滚动查看。大图加载失败有明确提示与重试入口。
2. 关闭按钮和 Escape 均关闭预览，恢复原先文字页滚动位置、焦点及文本选区。弹窗打开时限制背景滚动，关闭时恢复；延迟图片回调不能重新显示已关闭的预览。
3. “定位原文”及弹窗内“在阅读器中打开原文”保留管理页控制器、DOM、页码、标签、滚动位置、焦点和选区。阅读器显示“返回文字核对”；从管理页其他标签进入时显示“返回文献管理”。返回恢复原上下文，不重新加载文字。离开这一往返路径时清理保留状态。
4. 本页文字增加可折叠章节导航，宽屏位于文字左侧，窄屏移至顶部并默认收起。章节按钮和标题树均切换到对应页的提取文字，并定位、标记文本块；使用文档、解析版本、页码及块标识匹配，必要时仅接受唯一可靠坐标匹配。无法匹配时明确说明，不猜测位置。
5. manage.css、manage.js、reader.css 和 shell.js 的资源版本更新为 20261013-source-return1。
