# CSV 与受控绘图服务

日期：2026年10月8日。此步骤实现数据处理服务，页面入口另行集成。

新增 `visualization.py`，支持 UTF-8/GB18030 CSV、字段与缺失值预览、数值校验、明确选择忽略无效行、Min-Max 归一化、折线图与柱状图、数据版本绑定及真实数值图注。SVG 使用固定模板直接渲染，不执行模型或用户提交的 Python。导出 Python 脚本复用相同模板，输出以独占创建方式保留已有文件。

结构图支持显式节点和连接的 SVG 渲染，拒绝不存在的节点。文本写入 SVG 时转义。当前最多 10000 行 CSV，单图最多 500 个有效数据点；超限明确拒绝而非静默截断。三维雷达图的比赛口径尚未确认，本步骤不以普通雷达图冒充该条目完成。

验证命令：`.\.venv\Scripts\python.exe -m pytest tests/test_visualization.py -q`，3 项通过。覆盖缺失值决策与行号留痕、替换数据后图形变化、负值/常量归一化、非法 CSV、SVG 文本转义和连接校验。当前使用标准库，无新增依赖安装或外部数据传输。
