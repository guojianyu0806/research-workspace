# 无模型依赖的文献版本比较

## 范围与状态

本轮继续软件开发，暂停真实Pro付费复测。实时检索、全文核验和方向筛选的完整真实验收仍为待完成，沿用076记录中的中断状态；没有重试、改写或补造旧任务结果，也不以本地测试替代真实模型质量验收。部署、远程发布和参赛材料继续暂缓。

当前补齐的是文献版本比较：从逐块按序配对升级为区分大小写的正文token比较。空白和文本块边界本身不算文字修订，数字、大小写、标点及数学符号仍参与比较。不同PDF图片内容、未提取公式、语义等价和移动修订不在该算法确认范围内。

## 行为与修复

- 两侧文献及解析版本在同一SQLite读快照中选定，支持显式历史`run_id`和`other_run_id`。默认使用最近可读的完成版本；运行中重解析不会替换本次比较来源。未结束或归属错误的版本拒绝比较。
- 每处修改保留实际新增、移除或替换的文本，以及所有跨文本块区域。原块正文不改写；`change_span`的起止位置和片段逐项对应原文。PDF定位精度仍为文本块，不冒充逐字符高亮。
- 旧算法大小写归一化会漏掉BERT与bert这样的变化；新算法保留大小写差异。换行或分块变化不再自动成为文字变化。
- 返回固定解析版本、原文件SHA-256、正文快照摘要、处理覆盖范围及部分解析提示。网页将据此展示版本选择和片段核对，前端验收另行记录。
- 每侧最多200万字符、6万个token；匹配工作量采用候选配对估算上限200万，输出最多200处修改、2000个源区域和60万字符。达到限制时明确标为资源受限或输出未完整，不得解释为没有差异。
