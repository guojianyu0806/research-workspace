# 缺失主字符时的孤立下标修复

初轮独立验收检查了“不补回被擦除的beta”，进一步检查发现该条件仍不充分：beta被删除后，残留的t虽然未被拼回beta，却被当成正文变量，产生`\sqrt{1-t}`。这不能作为该扫描结构的完整恢复。

新增同一操作数内部的基线复核：仅使用本操作数中自身两次OCR一致的全高数字作为参照。相对该基线明显下移、字号较小且没有所属主字符的字形，保留原OCR及源位置，标为`unresolved_orphan_lowered_glyph`，完整LaTeX为空。参照字形、OCR和孤立下标各自绑定原页，界面提供独立定位；不从其他操作数或相邻行补写主字符。

更新负例，要求删除beta后整行保持未完成，而不只是“结果与原式不同”。修复后8项聚焦检查通过，用时47.96秒，包含真实7行全部转写及7项擦除反例。首轮正例结果没有因此改变。之前60/60的独立验收只代表当时较弱的负例条件，不能替代本修复的重新验收。

证据为`artifacts/multiline-20261018-continue/orphan-fix.log`及`orphan-fix.xml`。新的全量回归、独立验收及API/界面复测另存，不覆盖旧记录。未调用模型、安装依赖、部署或准备提交材料。
