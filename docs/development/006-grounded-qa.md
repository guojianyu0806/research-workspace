# 模型接口与原文约束问答

日期：2026年10月8日。

实现兼容 `chat/completions` 的异步模型接口、超时及限流的有限重试、JSON 输出校验、中英文词法 BM25 检索和单篇/多篇问答。每条结论必须关联本次检索的证据编号及原文引句；未知证据或原文不存在的引句被拒绝，多文比较要求各选定文献均有引用。

实际运行 Prompt 保存在 `research_workspace/prompts/qa_v1.txt`，版本为 `research-evidence-v1`。结果保留检索、调用、校验等可观察步骤，不保存模型隐藏推理。未配置服务时明确失败，不输出模拟问答。

验证：`tests/test_intelligence.py` 初始13项离线测试通过，使用HTTP模拟传输验证协议、重试、来源绑定与拒答，不代表线上模型回答质量。检索目前为词法BM25，不包含语义向量或跨语言嵌入。原文引句存在不等于语义蕴含已被证明，真实问题验收仍需核对。

配置使用 `RESEARCH_MODEL_BASE_URL`、`RESEARCH_MODEL`、`RESEARCH_MODEL_API_KEY`。本步骤未读取用户密钥、调用付费模型或向外部服务发送论文；实际模型配置与效果验证仍待后续完成。
