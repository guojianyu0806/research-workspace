# 扫描公式嵌套组合与矩阵字母复核

本阶段继续本地软件解析，不调用模型、不新增依赖，不涉及部署与比赛提交材料。输入为已有公开资料在隔离环境中生成的纯图像页面，扫描通道不能读取对应原生文本或字体答案。原始PDF和保存解析保持不变。

## 已实现行为

- 增加`raster-composition-v1`：按可见分数线、操作数范围、根号和上下标位置组合嵌套结构。已有独立观察保留为子节点，未知子项不能用上下文补全。实际覆盖包含“分式→根号→下标”及“分式→分子→转置上标”。
- 在有界主行区域内观察文字、括号、等号与末尾标点，检查未归属墨迹、子项状态和有限表达式语法。只有通过检查才输出`whole_equation`；失败保留`incomplete_equation`及各次观察。完整状态指有限转写候选，仍须人工核对，不能视为数学正确性证明。
- 组合通道单页最多96次额外OCR，结构深度上限8、节点上限128；原有页面像素和局部区域限制继续执行。求和仅恢复符号与上下限，尚未恢复任意复杂被求和项、多字符脚标或一般嵌套根号。
- 对不确定矩阵字母增加144/288DPI局部复核；只在同列存在已观察的小写主体字高及上伸字母字高时核对大小写。参照仅提供几何尺度，不能提供目标字母。两次新读取仍须一致，原`C/Cc`冲突记录保留，不执行统一小写转换。
- 增加矩阵行间距保护：擦除中间元素导致异常大行距时，保留观察和原图，不把三行向量静默输出成完整两行向量。
- 版面版本更新为`local-layout-v8-scan-composition`；嵌套子项及审核记录递归关联文献、解析版本、页码与旋转后归一化坐标。字高参照也有独立锚点。界面逐层展示并可定位、返回；前端缓存标识`20261017-scan-composition1`。

## 阶段验证

新增组合测试初次发现：参数列表的逗号被旧通道列为失败的微小下标候选，造成完整文字观察被阻断。已保留原候选记录，并调整组合的结构候选判断，使逗号仍由完整文字片段的观察读取；未用预存公式修补结果。

修正后组合测试17项通过；补充旋转字高参照后，组合、既有扫描数学和数值复核32项通过；随后擦除矩阵字母的独立反例1项通过。首轮失败记录不计为通过。最终全量回归及扩展资料验收另留阶段记录。

实际资料中的Attention完整等式与Sigmoid完整等式已在聚焦测试中恢复；擦除闭括号或根号内容后不能输出完整等式。低清144DPI的三个矩阵/向量分别恢复9个数字、`a,b,c`及`b,c,a`，其中后者的小写`c`保留初始冲突、两次复核和字高依据。

这些结果只覆盖现有资料与测试条件，不能推断任意字体、分辨率或官方资料包的通用准确率。所有结果继续标记待人工核对；未知内容不猜测补齐。
