# 全文条件覆盖与保守方向筛选

## 行为与证据边界

在未来方向的有界 PDF 正文核验之后，固定原始设想的逐字条件清单。所有非空白字符必须按原顺序覆盖，包括数值、否定、范围和标点；规划遗漏时保留整个方向，不以缩短后的条件执行筛除。

每个条件独立检索固定解析版本的正文，生成自己的完整引句并单独审核。只有所有条件均充分覆盖，且同一篇完整解析论文中的兼容方法或实验通过联合覆盖审核，才移出重点候选。部分覆盖、未知范围、解析不全、无效引句以及跨论文拼接均保留。该判定仅针对本次实际证据，不证明普遍已解决或研究新颖性。

原始章节、历史结果、未通过的诊断和原始方向均保留。筛选结果分别列出保留与移出候选的方向，不物理删除记录。条件、引句、解析版本、内容摘要编号、方向判定编号及独立审核相互绑定，页面和导出逐条展示。历史正文任务可以另建筛选任务重新核验，不回写旧结果。

## 实现与验证

各付费响应按步骤保存；取消与重试复用已经保存的响应。任务总量依据真实条件清单计算，失败诊断不计作完成步骤。新建未来方向任务默认启用本流程，旧任务载荷保持原有语义。

初轮全量回归 743 项通过；新增测试之后，11 项筛选专项通过，包含充分覆盖、部分覆盖、证据不足、引句伪造、限定条件遗漏、实验不兼容、跨论文拼接、解析不全、取消恢复、同一调度周期衔接以及账号隔离。测试使用明确标注的合成 PDF 与离线模型替身，不作为真实 Pro 验收。对应初轮全量产物：`artifacts/regression-future-filter-20261017-v1.xml`。
