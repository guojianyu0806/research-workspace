# 扫描上下标、根号及求和片段

像素通道新增有限上下标对、带实际横线及勾形的根号范围，以及Sigma形状与希腊文OCR共同核对的求和符号。主字符、上下标、求和上下限分别识别；任一部分不一致则不输出完整片段。扫描函数不读取原生文字、嵌入字体或参考答案，不通过相邻公式补限值。

上下标仅处理分离的单字符，要求大小、水平距离及垂直偏移符合有限条件。修复初始的跨行误配和普通p/t、h/y上伸下伸误配，且仅在本地OCR检出的较短等式区域附近尝试。根号需要可见横线、上升斜杆和低位勾，操作数另行核对。求和需要实际Sigma形状和已授权项目希腊OCR的两个观察一致；上下限各自保留原图裁图与两次观察。

288DPI纯图像副本中，Attention第3页恢复`\sqrt{d_k}`和`K^T`，教材第33页两个求和均恢复`\sum_{i=1}^{I}`。只恢复数学子表达式或“运算符及上下限”，不声称恢复整条等式或被求和项。测试还抹除第一个求和上限：该处保留未识别，没有复制第二个上限。

每个结果、操作数和OCR记录在版面JSON中独立保留文献、解析版本、物理页及旋转后归一化位置。原始OCR观察与空白归一化文本分别存储。页面提供上下标、根号内容、求和上限/下限、运算符原图入口及返回。

新增6项测试与既有扫描数学4项合计10项通过，含0/90度位置、原件和保存解析不变、抹除限值与普通文字负例；JavaScript语法和差异检查通过。每页扩展通道限制8000个连通域、80次局部OCR，与既有表格/基础公式预算分别记录。低清或字体变化仍可能无法确认，一般扫描公式、复杂多字符上下标和嵌套表达式尚未通用支持。

此阶段使用已有依赖和语言数据，无安装、下载或模型调用。直接修改源码，新增测试与内部记录；原PDF、旧解析、图片、报告均保留。部署和比赛提交材料未执行。
