# 有引用依据的局域图谱

日期：2026年10月8日。

新增 `GraphService`，图谱边明确为“A引用B”，由参考文献中的标识或足够明确的完整标题匹配产生。边保留文献、解析版本、页码、原文块及区域；同主题相似度不产生引用边，身份冲突或多义匹配保留为未确认项。外部元数据节点与有全文的本地节点区分。

采用有向PageRank、入度和出度描述当前所选文献集合中的相对中心性，不能据此断言整个领域的学术地位。后续交互图界面会使用同一节点、边和证据记录。

验证：12项图谱测试通过，含21篇生成的测试PDF、20条已知引用构成的链；核验原文位置、含糊标题、版本标识、标识冲突和无关主题不连边。测试数据是可控夹具，不等同于20篇真实专题论文的最终验收。
