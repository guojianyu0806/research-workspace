现代科研工作台视觉体系
日期：2026-10-14
源代码版本：995ef96（feat(ui): 统一现代工作台配色与卡片层级）

一、目标与设计决策
本阶段将现有科研助手调整为现代工具界面，提高操作识别度和内容卡片的层级，同时延续阅读空间、可调侧栏、原文定位与页面返回等已实现行为。

主色采用亮蓝 #315ce6，承担主要操作和当前选中状态；正文采用深色 #1c2740，白色 #ffffff 承载内容，冷灰 #f4f6fb 区分工作背景。青绿 #08776d 用于就绪状态，琥珀 #8c581b 用于证据和原文核对。辅助文字和描边分别由共享变量控制，不依赖大块深色导航建立分区。
标题与控件采用 Segoe UI / Microsoft YaHei，以字重和字号建立层级；工具标签和数据沿用 Cascadia Mono / Consolas；论文段落保留现有衬线阅读样式。界面文字维持现有可读字号，不压缩正文来腾挪空间。

共享布局：
  品牌与全局操作
  六个模块的图标导航 + 平滑移动的选中背景
  阅读模块：文献侧栏 | 原文画布 | 按需展开的证据栏
  其他模块：页面标题 / 上下文选择 / 工作卡片与结果

视觉识别集中在叠页品牌符号、蓝色导航选中块及结果卡顶部细线。阅读界面保留紧凑工具栏；其余模块统一外框，不增加展示型首页或与科研任务无关的装饰。保留证据区的暖色，便于区分生成结果和核对来源。

二、实现
- 新增 research_workspace/static/modern-theme.css，在组件样式之后加载，集中维护色彩、字体层级、卡片、控件和弹窗外观；布局与交互仍由原组件管理。
- index.html 为六个模块补充 SVG 图标，图标标记 aria-hidden，按钮可访问名称保持不变；添加主题资源版本号。
- 顶栏和导航改为白底，选中项为浅蓝滑动背景，统一悬停与键盘焦点；保留减少动效设置。
- 文献、任务、发现、图谱和数据卡片采用统一圆角、细边框和轻阴影；减少重复通栏灰底和标题色条，结果区域更突出。
- 主按钮及其悬停色统一为蓝色；成功就绪状态用青绿，原文预览与引用证据保留暖色。
- 保留侧栏拖动、PDF 缩放与位置、全屏和专注阅读、章节导航、翻页滚动保持、原文预览返回、悬浮提示的计时与悬停行为。
- 五个显式列出样式的离线组件夹具同步加载主题，并记录主题哈希；未放宽测试断言。
