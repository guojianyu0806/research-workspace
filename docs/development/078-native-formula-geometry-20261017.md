# 原生二维公式与扫描表格的本地验收

本阶段不依赖 Pro，仅使用已安装 PyMuPDF、本地 Tesseract 语言数据与现有 NumPy。没有安装依赖、下载模型、调用付费服务、部署或制作参赛提交材料。

## 公式结构转写

新增原生字形几何解析，依据 PDF 中真实可观察的字形、基线、字号及矢量横线恢复有限分式、带覆盖线的根号、上下标和嵌套表达式。输出 LaTeX 候选、原始文字、字形位置、水平线段、方法版本及文献/解析版本/物理页/区域锚点；所有输出保留待复核状态。字形基线另以未旋转 PDF 点为单位明确标名，不与归一化显示坐标混用。

本地页分析及 JSON 导出已接入。字形不全、区域中存在未归属字形、未知字体映射、无法分解的多行等式及求和上下限不生成完整 LaTeX。不会将 Computer Modern 扩展字体中表示求和的 `X` 误写成变量 X，也不会把求和下限 `i=1` 当作完整独立等式。最多分析 15000 字形、5000 绘图路径、40 个种子式；递归深度和单式字形数另有限制，超限明确标记。

修复实测发现的漏转写：不同字体的 `model` 下标、字面下划线、跨小字形链的指数，以及分数线略长于文字区域时被遗漏。多行等式、说明文字混排及上下限的异常结果经重新测试后均保持原文和不支持原因，不以残缺转写宣称成功。原生观察不自动替换研究问答使用的旧解析文本，OCR 候选也不会自动成为已确认引用。
