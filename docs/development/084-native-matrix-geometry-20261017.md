# 原生矩阵的独立元素解析

通过实际嵌入字体的括号字形名称，匹配左右括号及上下部分，再按原生基线、字距和列对齐划分元素。仅在行列完整、每个元素可解析时输出bmatrix；不把空缺元素补成零，不把嵌套矩阵扁平化。

已有教材第461页的3×3置换矩阵及两个列向量、第462页的3×3参数矩阵和三个列向量已逐项检查。参数下标由实际字体大小和基线恢复。结果及每个元素在版面JSON中保留独立文献、解析版本、页码和归一化区域，页面增加矩阵审核记录和元素定位入口。

新增6项测试覆盖真实数字与希腊下标、嵌套拒绝、删除元素后不补零，以及0/90/180/270度旋转的来源一致性。与原生公式及版面测试合计29项通过。初次联调发现局部变量遮蔽页面变换矩阵的问题，已改名修复并重新通过全部四种旋转检查。

此阶段不支持任意括号字体或嵌套矩阵完整表达。扫描通道另行实现与验证，不使用原生内容填充扫描结果。旧PDF、旧解析及历史报告保持原样。
