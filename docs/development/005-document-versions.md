# 文献元数据与论文版本关系

日期：2026年10月8日。当前步骤提供服务接口，工作台入口后续集成。

新增标题/作者编辑、可恢复归档、正文五词片段指纹与 arXiv 标识候选匹配、显式保留或选择当前论文版本，以及保留两侧原页坐标的文本块差异。归档不物理删除文件；选择当前论文版本也不覆盖原始 PDF 或历史解析记录。

候选匹配是一种可解释的启发式方法，不等同于通用语义去重。相同主题不自动合并；候选必须由用户确认。旧版本从默认全库检索中排除后，仍能通过原文献和处理记录定位旧证据。
