# 文献阅读与证据工作台

日期：2026年10月8日。状态：本地浏览器流程已验证。

## 实际功能

三栏工作台提供文献库、原页阅读和证据检索。支持选择或拖入多个 PDF、任务进度更新、文献过滤、翻页、当前或全部文献检索，以及点击匹配片段跳转至对应页并标出区域。窄屏下切换文献、阅读、证据三个视图。

重新提取文字会创建独立处理记录，旧处理结果继续保存。界面明确标识当前为关键词检索，没有生成式回答；扫描件等无可提取文本页面仍可阅读原页，但不能据此生成检索证据。

## 浏览器验证

使用现有 Playwright 运行库和本机 Edge，启动独立无登录浏览器上下文。没有安装新的浏览器或 Node 依赖。测试连接实际运行的本地 API 与后台 worker，未使用模拟接口。

验证脚本：`scripts/browser_smoke.cjs`。输入为 Attention Is All You Need 的 v7 和 v1 公开 PDF，脚本会在目标本地工作空间导入样本并创建一次重新解析记录；建议在测试工作空间运行。

本机调用方式（将占位路径替换为已有运行库和浏览器的真实路径）：

```powershell
$env:PLAYWRIGHT_MODULE = '已有 Playwright 模块目录'
$env:BROWSER_EXECUTABLE = '已有 Edge 或 Chromium 可执行文件路径'
node scripts/browser_smoke.cjs data/samples/1706.03762v7.pdf data/samples/1706.03762v1.pdf
```

`SMOKE_URL` 可指定已运行的本地测试服务地址，默认为 `http://127.0.0.1:8765`。脚本不下载样本或依赖。

实际通过的流程：

1. 初始工作台显示，API 和后台 worker 可用。
2. 两个 PDF 批量导入、后台处理完成、原页显示。
3. 再次上传相同文件，文献数量保持不变。
4. 跨文献关键词检索，点击后文献、页码和高亮区域一致。
5. 当前文献范围有效，无匹配结果时显示信息缺口。
6. 跳至第 15 页，重新解析后旧处理记录仍可访问。
7. 390×844 窄屏三个视图均无页面横向溢出；1440×1000 桌面布局及手机截图已人工查看。

浏览器脚本错误和控制台错误均为 0。结果及截图：`artifacts/browser/2026-10-08T14-01-53-235Z/`。大体量产物留在本地，不进入源代码仓库。

首次浏览器验证发现检索范围的 `option` 标签闭合错误，使缺失 DOM 元素被误报为连接失败。已修正并重新完成上述流程；初次失败记录保留于同级时间戳目录。仅有 JavaScript 语法检查不足以发现此类 HTML 与脚本关联问题。
