# 扫描数学表头的字形与上下标分区

使用真实栅格的连通域、基线和分隔范围，将主字符与小号下标分开交给本地 OCR。不同高度或横向遮叠无法可靠归属时不强行恢复。对于短下标的重复字形，还要求墨迹高度一致、形状相似及两次独立字符识别一致；保留单独字符的原始大小写与原词观察，避免把实际 `ft` 改成 `ff`。

希腊文数据只用于有限的单字符补充通道，没有改变整页 OCR 的默认语言。数学单字符的语言原始观察与归一化结果均保留。科学计数量级的横向交叉字符、数字和实际抬高的指数分区识别；生产逻辑没有写入某一论文的数值或表头清单。

已有 Attention 扫描页的 `d_model`、`d_ff`、`d_k`、`d_v`、`P_drop`、`ε_ls` 与 `×10^6` 已逐项恢复，均带原图区域与解析版本锚点，页面可查看 LaTeX 和初始 OCR/复核记录。独立验收还检查 `PPL / BLEU / params / (dev)` 等邻近标签未被替换时误删；初次联调发现的 `params` 标签误覆盖已通过限制字词中心归属修复。

最新验收 `artifacts/scan-tables/20261017T111628460660Z/` 的 14 项断言通过：两张表的结构及区域、文件指纹、全部非表头文字和数值、数值复核记录、六个下标、指数、邻近标签与数学锚点。37/39 格仍与原生提取文字在空白归一后完全一致；两格数学表头已经转换为显式上下标文本，与原生提取的分散字形/多行顺序格式不同，不能把格式不同计作新的文字完全一致率。数学字段以独立的逐项结构断言验收。

新增独立栅格测试覆盖 `ff / ft / model` 下标、`×100^3`、普通文字不虚构上下标、预算耗尽，以及从现有原生论文重新栅格化后的纯图像识别。每页表头 OCR 最多 48 次，数值附加复核仍限 24 次。候选与人工确认严格区分；不宣称支持任意扫描公式、倾斜文字、未知符号或所有字体。
