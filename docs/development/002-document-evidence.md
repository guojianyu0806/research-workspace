# PDF 文献库与原文证据服务

日期：2026年10月8日。状态：后端功能已验证，浏览器操作验证另行记录。

## 实际实现

- PDF 校验、批次中的单文件导入接口、SHA-256 完全重复识别；原始文件按内部编号保存。
- SQLite 持久任务队列与独立解析进程，逐页保存文本、页面尺寸和归一化区域坐标。
- 解析中断后恢复；重新解析生成独立记录，保留历史证据。新任务未成功时，默认读取上次可用结果。
- 文献列表、任务进度、页面图像、原文关键词检索及证据定位接口。
- 对旋转页和裁剪页转换区域坐标；无可提取文本、部分完成和失败状态分别记录。
- 仅面向本机的 Host/Origin 校验、上传大小限制和内容安全策略。

依赖已按用户授权安装到项目 `.venv`，`pip check` 通过。Git 提交邮箱已按用户确认设置在本仓库，未更改全局身份。

## 当前限制

以上样本不是比赛官方资料包。本阶段验证的是原生文本提取、持久任务与原文定位，不代表 OCR、公式和表格结构识别、语义去重、跨文献推理或大模型问答通过验收。无文本页面可能是扫描图像，也可能是空白页，不能仅据此断言需要 OCR。

当前是本地单工作空间，无用户认证和公网部署能力；运行时应绑定 `127.0.0.1`，使用一个应用工作进程。尚未接入商业模型或发送文献内容到外部服务。

AI 协同用于实现、独立审查和验证。审查发现并修复了流式超限错误码、无效 Origin 解析、重新解析期间旧证据可用性问题；实际验证结果如上，未编造模型输出或隐藏推理记录。
