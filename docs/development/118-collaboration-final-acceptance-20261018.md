# 跨用户协同推荐最终验收

## 实际交付

功能代码版本`6749cc8`：独立账号可在“发现与追踪 → 本地推荐”主动加入或退出本机协同推荐。默认关闭，本机默认空间不参与；没有自动为实际账号加入或创建示例账号。界面在加入前说明共享范围，详细说明可展开。

群体计算只读取用户主动共享的公开arXiv标识与喜欢/不喜欢值；参与映射使用服务端账号UUID。候选、文献关系、标题摘要、下载状态、代码核验状态及本地原文关联仍只来自当前账号自己的工作空间。不会打开其他账号的文献、笔记、查询、订阅或任务，也不返回邻居身份、逐人反馈或原始投影。

至少2篇共同喜欢、至少3个其他参与账号及至少3个同向候选反馈才能有限调整排序；本人明确反馈优先。不同版本合并为一个公开标识，按最新反馈确定当前信号；清除及退出移除共享投影，个人反馈及原文保留。最多500篇个人投影、500个参与账号、100个邻居；先重排完整有界本地候选池，再截取前20项，协同加减分不超过0.75。样本不足、候选依据不足或共享库暂不可用时返回个人推荐。

这是同一部署内的协同排序，不是外部推荐服务或联邦学习；不调用模型、不新增联网检索。最小群组不是差分隐私或完全匿名保证，汇总仍可能反映参与者兴趣。本轮不证明真实用户推荐质量或点击率提升。
