# 保守语义去重实现阶段

本轮补齐本地文献去重：三处正文抽样的本地向量用于发现候选，论文自身标识和主要正文指纹用于身份核对；语义相似本身不能触发分组。扫描、审核、分组与撤销记录分别持久化，不删除PDF、解析、文本块或研究任务引用。

同一论文候选要求完整可读正文、至少200个正文词项、论文自身标识一致且五词指纹Jaccard重合不低于0.35；完整可读主要正文逐字归一空白后一致，也可作为需要人工核对的副本候选。该一致性摘要保留大小写和Unicode字符，不把大小写不同的数学变量视为相同。主题相近、标识不同/冲突、正文过短/部分可读均不得由去重入口确认分组。已有版本组不跨组传递配对结论。

自身arXiv标识只接受第一页明确标签及合理页眉/页边位置；正文引用和书目不作为自身标识。文件名只是辅助信息，若与正文标识冲突即拒绝分组。原有版本分组入口也检查已验证的身份冲突，包含被跨组合并的其他成员，防止绕过新入口的保护。

确认操作在写事务内重新读取元数据、解析和全部块摘要，并重新计算身份资格。来源变化时拒绝旧扫描。确认后只改变常用版本关系，原文和历史引用保持各自身份。撤销保留审核及旧关系记录；若发生后续版本组选择或成员变化则拒绝覆盖，以免破坏后续操作。

扫描上限60篇文献、每篇25万字符、总计300万字符、显示120对候选，超限和不可读来源明确报告。语义不可用时如实显示正文/标识依据的降级状态；不伪装完成语义扫描。所有分组须人工核对并确认，不默认合并。

当前相关核心回归110项通过。真实本地向量在四篇公开论文和两份明确标记的派生PDF上通过53项检查：Transformer不同版本及改名副本可作为候选；BERT/RAG及误导文件名不被误合并。确认、重解析、撤销后全部旧页、引用夹具任务和PDF原字节不变。夹具仅验证存储完整性，不冒充模型回答质量验收。

真实初轮验证脚本曾假定不同论文一定出现在候选列表，因低于候选阈值而中断；后续报告显式保留不同自身标识的拒绝配对，重跑通过。首轮中断保留，不计入最终通过。页面、HTTP和主服务验收将另存最终阶段记录。

不安装依赖、不下载模型、不调用Pro；Pro完整流程仍待验收。没有开展部署、远程发布或比赛提交材料。旧PDF、历史报告和验收产物保持原样，源码在本轮授权范围内直接修改。
