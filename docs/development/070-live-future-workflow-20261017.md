# 实时最新论文核验与方向筛选接入

## 行为

新建未来方向任务默认强制请求官方 arXiv 接口，并限定最近90天的论文提交时间。页面可选最近30天、90天或一年，也可明确允许缓存；旧任务未携带这些选项时保留原语义。缓存仍按查询、字段、排序、上限及时间窗口区分，不以删除缓存伪装实时请求。

每次成功联网保存原始 Atom 响应、请求起止时间、实际URL、回执编号、字节数及SHA-256。强制实时模式拒绝缓存或早于本轮的回执；原始响应与历次任务保留。返回的发表时间再次按窗口核对，不把过期或未来记录纳入当前来源。来源和查询回执相互关联，页面及导出可核对。

原有公开摘要核验、最多三篇官方PDF获取、固定解析、正文结论审核及逐条件自动筛选继续衔接。全文方向记录自身实时查询依据；查询未完成、缺少回执、命中缓存或未覆盖本方向规划条件时，不能用于自动筛除。`future-filter-v5` 保留原有逐字条件、完整支持、正向实现及同篇联合审核门槛。
