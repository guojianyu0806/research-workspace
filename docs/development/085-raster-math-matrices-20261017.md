# 纯图像公式与矩阵的有限本地解析

本阶段在既有OCR和数值库上扩展像素通道，不安装或下载组件，不使用Pro。只在无原生文字的扫描页按需分析；原生文字与参考答案不进入扫描算法。既有表格区域排除，避免重复解释为矩阵或分式。

## 实现范围

扫描方括号矩阵通过连续竖线和上下横臂检测区域，再按真实墨迹分行、分列。每个简单数值或单个拉丁字母保留两次OCR观察，须一致且满足有限格式才能成为待核对元素；任何元素缺失、不同或行列不齐，均不输出完整矩阵，不补零。嵌套、上下标和一般复杂元素仍超出当前扫描矩阵支持范围。

扫描分式以像素水平线及上下可见操作数为依据，分别复核分子、分母；仅输出有限子表达式，明确标记`partial_formula_needs_review`及`scope=subexpression`，不声称恢复整条等式。显式标量赋值仅在多次OCR一致、格式受支持且未观察到下沉小字形时转换。未知希腊字母、上下标、根号、求和或复杂函数不通过文字补写。

结果、矩阵元素、分子和分母均保留独立文献ID、解析版本、物理页及归一化区域，来源为不可变PDF原图。OCR的阈值、分割模式及原始观察随JSON导出，未接受的观察仍保留；不以模型审核代替原图。页面提供矩阵元素、公式及操作数定位和审核记录。

预算：扫描页最多400万初始像素，单区域最多20万渲染像素，矩阵12个、分式8个、标量/未支持候选16个；局部OCR预算128次，另一次全页候选定位。原生矩阵预算与扫描通道独立。一般未知扫描公式仍不支持。
