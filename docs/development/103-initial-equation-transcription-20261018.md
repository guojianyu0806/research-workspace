# 多行扫描推导的起始表达式与等号链

## 实现范围

在现有教材物理第376页的纯栅格输入中，两组推导各有一条不含等号的起始表达式，随后分别有2条、5条等号续行。本轮新增有界的起始式识别通道，保留此前7条续行的独立编号和审核树，以原页的实际行序组合完整等号链转写候选。

候选必须位于第一条等号续行之前，具有受支持的行距、横向范围、分式或根号横线，以及无干扰墨迹的行间区域。每条起始式由独立的RowReader读取自身288 DPI像素，最多384次OCR；不读取原生文字、测试预期、文档身份或后续行答案。最多处理4组。缺失、歧义或未解析的起始式不能从其他组复制，也不补写函数名。

起始式另存为`initial_expression`，不改变原续行操作数数量和`source_row_number`。确认起始式后，各续行保存同组起始式引用；只有起始式及所有续行均完成时，组合结果才标为`whole_equation`。这里表示观察到的等号链转写完成，`mathematical_equivalence_verified`仍为false，字体粗细及向量语义不在本轮确认范围内。

## 实际识别冲突与处理

- 两处拉丁x分别被希腊OCR识别为κ、π。新复核要求自身两次英文观察支持x，并在两个阈值下观察到四臂、中央收窄的交叉笔画且不存在左侧竖干。原希腊结果和冲突记录仍保留；不将任意希腊字符统一替换为x。
- 第二条起始式中的根号钩有2个实际对角相邻像素被四连通分割拆开。只合并满足范围、大小和实际八邻接的细小墨迹，不填充间隙或新建像素。完整墨迹集合须保持不变。
- 首次审核JSON写出遇到NumPy整数类型，修正为普通整数；失败探索日志保留，不作为验收通过证据。

新增原始区域、候选、起始式引用、字形冲突和几何区域均通过统一版面导出转换为当前文献、解析版本及旋转页面坐标。网页提供起始式与各续行的独立原文入口、OCR冲突入口和返回操作。版面版本为`local-layout-v14-initial-equations`。

## 验证状态
