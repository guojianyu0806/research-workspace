# 原生PDF版面结构分析

日期：2026-10-09。对应 M1 结构提取与 M3 原文核对。

新增 LayoutService，按需分析单页原生文字、字体与位置。输出标题、作者、机构、章节、附录标记、单/双栏阅读顺序候选，线框表格的真实单元格，嵌入图像区域及邻近图注，数学符号候选。每项保留文献、解析版本、页码及归一化渲染坐标；只有与持久化原文块确切匹配才附加 block_id。原始PDF只读，结构分析不会修改已有解析块或自动覆盖元数据。

公式仅支持显式线性符号的有限LaTeX转写。复杂二维公式、隐式乘法和多字母语义不猜测，保留原文并标记复核。扫描页不冒充原生结构；无边框表、矢量图语义、复杂混排与作者机构的真实性仍未解决。文档概览只分析第一页，再组合已有文本标题与附录标记，避免长论文入口无条件扫描每页。

本机PyMuPDF 1.28的表格检测会受页面旋转影响，实现对独立打开的内存文档临时归零旋转并恢复，统一映射回原页渲染坐标，绝不保存PDF。真实生成的测试PDF覆盖单/双栏、表格、图像、公式、旧版本/错属版本和0/90/180/270度旋转；逐字节验证原PDF未变化。

验证：11项新增版面测试及4项既有结构测试通过；本次与书目及发现服务合计54项回归通过。没有联网、OCR调用、模型调用或新增依赖。以上为合成PDF的确定性验证，不等于官方材料上的结构识别准确率。UI与API联调另行记录。

新增 layout.py、test_layout.py 和本记录；日期化资料与旧成品保留。
