# 长译文摘要与分页接口阶段验收

日期：2026年10月20日。资料冻结版本`6e9e9c2`，接口与测试版本`66eaf26`。属于121方案S5/G的后端步骤，不代表长书/复杂译文联动整体完成。

## 行为与数据边界

`GET /api/research/tasks/{job_id}?include_result=false`返回不含完整结果、检查点及逐次调用记录的任务摘要，附译文分段数量、固定来源、缺译/非法定位/重复标识统计、索引错误和版本号。事件最多返回最后100条，明确给出总数与截断标记。默认任务详情仍保留旧行为。

`GET /api/research/tasks/{job_id}/translation-blocks`支持offset、limit（1～200）、revision、block_id及可选include_index。正文保留原顺序和内容；索引仅含序号、标识、字符数及换行数，不含全部正文。唯一block_id可定位，重复标识返回400，不猜测位置。已保存结果/检查点变化使派生索引失效；旧revision返回409，防止跨页混用两次保存内容。

派生表与触发器只维护可重建的分页索引；不修改历史结果、检查点、原PDF或引用。完成结果优先使用已保存blocks的顺序；未完成任务沿用历史检查点rowid顺序，排除明确的审核/诊断记录。缺译、重复标识和错误解析版本的文本保留，定位能力另行标注。非标准JSON保留原记录并报告分页错误，不转换为伪成功结果。

两接口沿用账号空间鉴权。完整详情和Markdown导出维持兼容，不以分页长度截断导出；导出当前仍沿用原有完整结果读取方式，本轮没有改成流式导出。尚未修改前端选择/轮询入口，也未把原双语组件转换为窗口渲染。
