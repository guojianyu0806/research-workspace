# 单篇公开论文连续阅读工作流

日期：2026-10-17。发现页面选定论文后，可展开“下载、解析并回答问题”填写问题。一个任务依次保存公开原文、等待后台解析、固定解析版本、检索并生成经过已有引用/事实/完整性审核的问答。限一篇明确选定论文，不将其表述为自主研究选题或全网搜索规划。

下载及解析阶段保存检查点，切换页面不影响执行；已下载文件保留。取消后不发起下一阶段模型调用。解析失败会明确要求先修复解析，再继续原任务。固定版本属于当前账号且必须是稳定的completed/partial版本，不能借用其他文献、后续新解析或变化中的块。已保存的付费回答检查点可恢复而不重新购买回答。等待解析的排队任务有一秒领取间隔，避免后台忙循环。

工作流任务沿用用量台账、取消、重试、Markdown导出、原文定位和返回；发现页保留原列表。研究任务下拉不提供缺少论文选择上下文的独立创建入口，仅从公开论文卡片创建。

自动验证包括：下载/解析分阶段等待、同任务恢复、不重复下载/回答、新解析出现后旧来源不变、跨文献版本拒绝、取消保留文件、下载失败重试及跨账号API隔离。真实网络与Pro端到端验证待本阶段实现提交后执行。旧产物保留，源代码直接修改；未部署、未准备提交材料。
