# 公开研究正文核验阶段

未来方向任务在摘要初筛后增加有界的公开 PDF 核验。新 API 任务默认开启，旧任务及旧检查点保持原有行为，避免改变历史验收结果。

## 实现范围

- 从方向关联的实际查询返回中按轮次选择最多三篇论文，记录来源、发表和检索时间。
- 复用受限的 arXiv 下载入口，不接受模型生成的下载地址。保存文件指纹及不可变解析版本。
- 下载、等待解析、逐方向正文回答分别保存检查点。等待解析时释放工作轮次；重试复用已保存的模型回答。
- 每个方向只使用自己查询关联的已解析论文。复用问答的原句匹配、逐结论隔离审核、回答完整性检查与稳定结论标识。
- 页面逐条并列展示结论、所属引句、页码入口与审核；导出保留相同标识、解析版本和原始摘要初筛记录。
- 摘要相关性不等于方向覆盖。正文阶段保留全部原始设想，不自动宣称已解决或研究空白。下载失败、预算不足和无匹配证据均明确留缺口。

这是完整 PDF 的解析和正文片段检索核验，不是逐字穷尽阅读，也不保证覆盖全部最新文献。
