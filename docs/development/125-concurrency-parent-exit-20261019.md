## 故障与处理

隔离短预检 `20261019T153107559806Z` 在约120秒出现 Windows 原生访问异常，导致API进程退出、正常关闭路径未执行，实际worker仍存活。错误发生在周期线程诊断输出期间，关联不等于因果；目前不能认定原生崩溃根因已经修复。失败报告及stderr保留，没有删除失败轮次。

新增worker所属服务观察机制。API启动及模型配置重载时，均把自身进程编号传给两个worker。Windows仅申请所属进程的SYNCHRONIZE权限并保留句柄，独立观察线程等待其退出；所属服务结束或观察失败后，worker直接退出，避免继续执行未知任务及占用空间锁。手动运行且没有指定父进程的CLI行为保持。已提交的SQLite页面和检查点不改写，研究任务恢复继续遵循显式重试规则。

实现依据：[Microsoft进程访问权限](https://learn.microsoft.com/en-us/windows/win32/procthread/process-security-and-access-rights)、[WaitForSingleObject](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-waitforsingleobject)。不引入系统安装、全局配置或服务。
