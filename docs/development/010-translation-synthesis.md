# 分块翻译与学术生成接口

日期：2026年10月8日。

在已有真实模型接口上新增局部/全篇逐块翻译、中文文本学术英文翻译、专题综述、Future Work提取、idea论文框架及概念结构图描述。全文翻译列出全部所选页和缺失页，不通过截取前几页冒充全篇完成。结构图由受控SVG模板渲染，不执行模型生成代码。

可识别的数字、引用、代码及公式文本用保留标记保护，返回后核验标记和数字。当前解析未识别任意PDF的全部公式与代码类型，因此仍需核对公式识别与翻译质量。

综述和草稿要求来源内的原文引句；书目由实际本地文献记录构建，未核验的作者、年份、刊物不补造。Future Work目前只提取选定文献的方向，外部最新进展核验状态明确为证据不足，尚未完成“排除已解决方向”。

Prompt文件为 `translation_v1.txt` 与 `synthesis_v1.txt`。当前智能服务28项离线测试通过，包括分块、受保护内容、数字改变拒绝、来源约束、必需章节与结构图节点校验。真实模型效果尚待配置后验证。

读取/写入中断时不自动再次调用模型，明确提示服务端结果未知；安全的连接失败及明确的限流/服务错误仍作有限重试。HTTP模拟测试不代表实际产生过模型调用或费用。
