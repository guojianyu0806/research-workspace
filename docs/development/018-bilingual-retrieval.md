# 双语查询扩展与原文检索融合

日期：2026-10-09。对应 M2 跨语言问答检索。

新增 retrieve_for_question，在中文问题面向英文资料，或英文资料没有问题中的对应希腊符号时，按需生成至多6个短检索词组。每个词组必须锚定原问题片段，拒绝新增数值、控制字符、指令和URL等不合规输出。扩展仅一次HTTP尝试、512输出token上限；超时、非法输出等情况退回原问题BM25。纯英文精确检索以及没有自定义关注词的默认综述不额外扩展。

原问题与扩展查询分别进行BM25，使用RRF融合并兼顾各选定文献。所有候选始终来自调用前固定的文献/解析版本/原文块；生成词不作为证据。作者机构问题可额外加入各文献最早可读页的有限候选，页面信息仍由真实原文支持，不能由扩展词生成作者名称。问答及合成结果保存查询、模式、调用状态、Prompt版本和实际原文范围，失败拒答与引句校验保留。

真实运行Prompt为 `research_workspace/prompts/retrieval_query_v1.txt`；本次离线测试实际调用该模板配合明确模拟响应，尚未用真实DeepSeek服务评价其检索质量。本实现是双语词组扩展与词法检索融合，不是向量嵌入检索，也未解决泛化语义去重。生成扩展可能偏离意图，模型引句匹配不等于证明整句推论成立。

问答及合成接受取消回调；扩展结束后再次检查，已取消任务不会继续调用回答模型。同步 retrieve 保持无模型调用的纯BM25，兼容原使用方式。

验证：42项新增检索测试、3项真实JobStore取消测试，连同相关旧测试共98项通过；随后全项目回归301项通过。包括中文LayerNorm、作者机构、β符号、调用次数与token限制、失败降级、旧版本范围及取消传播。无真实模型请求、无新依赖。既有测试未为适配新行为而删减。
