# 公开论文检索与持久追踪

日期：2026年10月8日。

新增 arXiv Atom 检索、来源与时间记录、经官方元数据核对的 PDF 下载入库、24小时相同查询缓存、订阅与增量去重、失败恢复、文献库相关性推荐及点赞/踩反馈。后台仅执行用户在应用中启用的订阅；构造服务、浏览缓存和推荐不主动联网。

下载仅接受已核验 arXiv 记录，不允许任意 URL；限制响应大小并检查重定向来源。不同工作空间的元数据、查询和反馈分别保存，网络节流仅共享请求时间。推荐中的 GitHub 地址暂为待核验线索，不宣称代码可用或已经复现。

验证：`tests/test_discovery.py` 18项通过，使用离线HTTP传输验证 Atom 协议、缓存、下载范围、任务去重和偏好排序。本步骤尚未做真实公网检索；线上连通性与返回内容需另外验证。

主要接口依据：[arXiv API用户手册](https://info.arxiv.org/help/api/user-manual.html)及[API使用条款](https://info.arxiv.org/help/api/tou.html)。
