# 模型增量输出与审核边界

研究任务的问答、多文比较、综述、论文框架及翻译生成请求支持实际 SSE 增量读取。页面单独显示待审核草稿；结构、原文引句、事实支持和覆盖审核仍通过原流程执行，完成后才展示正式结果与引用。内部检索扩展、事实审核及模型私有推理不展示为生成正文。

一次流式请求对应一次模型用量回执，预览关联同一调用编号；仅累计服务商实际返回的用量，缺失不记为零。完整响应不合结构时沿用原有有限修复机制；断流、截断或协议错误不自动重购请求。兼容服务若直接返回完整 JSON，则消费同一响应，不补发请求或伪造打字动画。

预览最多24000字符，每次调用覆盖上一份草稿，写入节流80ms；事件流检查间隔100ms，前端使用原生EventSource接收最新快照，1.5秒轮询保留为最终状态回退。预览不生成引用链接、不进入导出、无HTML执行。结束、失败及恢复清理草稿；停止读取时关闭上游响应。HTTP输入上限2MiB，UTF-8和JSON转义可跨网络分片。

阶段验证：96项相关自动测试通过，20.49秒；`artifacts/model-stream-focused-20261018.xml`。覆盖提前观察增量、中文和转义分片、用量、取消、断流、错误码、有限重试、并发空间、原文位置与最终审核、导出隔离和恢复。修复了API中间件覆盖SSE禁止代理转换响应头的问题。

本阶段尚未完成真实HTTP浏览器联调及全量回归；不调用Pro、不代表真实模型内容质量验收，不执行部署或提交材料制作。旧报告与原始PDF保留。
