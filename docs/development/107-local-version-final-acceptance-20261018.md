# 本地版本比较阶段验收

## 范围与版本

本轮停止真实Pro付费复测，继续不依赖模型的软件功能。实时检索最新论文、全文核验和方向筛选的完整真实链路仍待验收，保留076记录中的原始失败/中断；没有重试或以本地替身代替真实验收。没有开展部署、远程发布和参赛材料。

后端提交`0fa5d17`固定双侧解析来源并返回原文修改片段；界面与复现脚本提交`3d5e22b`增加历史解析选择、上下文展开和逐块原页核对。106是实施中期记录，原样保留；本记录补充最终结果。

## 实际完成

- 比较在同一SQLite读快照中读取两侧已完成的历史解析，拒绝归属错误或尚未完成的版本。运行中重解析、默认版本切换不会替换已显示的来源。
- token比较保留大小写、数字和符号变化，忽略空白及分块边界。修改片段通过原文本块的字符偏移提取，不生成替代原文；跨块修改保留所有原区域。
- 界面支持选择两侧解析版本、显示实际修改片段、展开两侧原块上下文及跳转原页后返回。原页高亮精度为文本块，非逐字符几何定位。
- 限制字符、token、估算匹配工作量和输出大小；未完整比较显示明确状态，不能误报为没有变化。部分可读解析也有覆盖范围警示。

不据此证明论文身份、数学等价、语义等价、图片差异或完整语义去重；版本关系仍需人工确认。现存解析的阅读顺序可能造成新增/移除，移动不保证识别为移动。

## 保留的缺项与优先级

| 优先级 | 未完成或待验收范围 | 处理边界 |
