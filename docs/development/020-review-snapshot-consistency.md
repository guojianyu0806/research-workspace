# 综述补充证据的版本一致性

日期：2026-10-09。

复查双语查询扩展时发现：综述对未命中文献补充首页片段的旧路径会重新读取可用解析版本。如果查询扩展等待期间该文献完成重新解析，补充片段可能来自新run，而查询审计仍记录旧run。

修复后在首次读取原文时同时保存各文献的首页候选，综述补充复用同一快照，不再二次读取可用run。内部候选不进入公开retrieval审计；真实证据照常序列化与引用核对。

新增回归在扩展调用期间实际完成一次Library重新解析，确认传给合成模型的run、block、text与bbox均来自旧快照，并确认只读取一次原文集合。相关99项检查通过，随后全项目302项通过、1条既有Starlette弃用警告。最终日志：`artifacts/verification/20261009T0244318063699Z/pytest-final.txt`。

本修复直接修改 intelligence.py 和新增检索测试文件中的回归用例；此前提交 `ea2994e` 不重写。没有模型联网调用，没有更改原始论文和旧产物。
