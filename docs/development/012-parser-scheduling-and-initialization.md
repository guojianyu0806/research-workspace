# 逐页调度与首次访问并发修复

日期：2026年10月8日。

账号空间的解析原先会在一个活动进程中连续处理整篇PDF，后面的研究任务和其他账号需等待。现支持指定单轮页数预算，活动进程每个空间每轮处理一页，再处理研究任务和订阅；默认独立解析进程保持整篇处理接口兼容。每页完成后保存游标、证据和进度，重新排队并按最近调度时间轮转。单个复杂扫描页仍需等待本页OCR完成。

正常轮转不会反复重试已经失败的页；进程中断恢复才重置本轮游标，成功页与文本块ID保持不变。取消、单页重试和旧可用解析记录继续保留原语义。解析、调度、工作流及相关API共72项针对测试通过，包含541页合成文档。
