# 译文统一术语与原文不可变边界

日期：2026-10-17。真实107块整篇翻译的完整性检查通过，但逐页抽样发现n-gram在正文与表格中分别出现n-gram、n元组等不同译法。不能用“所有块有译文”替代术语质量验收。

增加可选任务术语表：文献翻译和文本翻译可在网页按“原文术语 => 统一译法”填写，最多50项；同一任务冻结术语映射，所有块与恢复步骤使用同一映射。独立词组按最长优先、英文大小写不敏感匹配，译文恢复时采用指定译法；源文本、固定解析、坐标和原始数字保持原样。公式、代码、URL和原本保护片段优先，术语不能替换其中内容。映射不能引入或改变数字、公式、保留标记或控制字符。原文显示仍使用原始值，绝不能把术语译法写回原文。

任务详情和导出保留实际术语映射。不自动重写已完成的整篇译文；改用术语表应创建新任务，保留旧结果。没有配置的术语仍可能存在译法差异，不能保证任意术语全局一致。
