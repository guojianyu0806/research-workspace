# 三维分层雷达图

日期：2026-10-09。对应 M6 数据可视化的三维雷达图要求。

本次实现采用明确的三维分层定义：CSV 的3至12个不重复指标行对应极角轴，2至6个数值列对应不同高度层，半径表示0至1数值。保存真实 x/y/z 坐标，使用正交投影生成 SVG，可通过方位角与仰角生成并保留不同视图。高度是系列类别顺序，不是额外测量变量。这是当前实施口径，尚未获得组委会对“三维雷达图”具体定义的确认。

未归一化数据必须位于0至1。启用归一化时，对每个指标行在所选系列间做 Min–Max 变换，而不是把不同指标混合比较；常数指标设为0.5并记录。两个系列可能因此被映射为0和1，图形反映当前样本的相对范围，不是绝对性能评分。原始值、每轴范围、相机、输入数据哈希和变换规范可下载，指标的优劣方向不自动推断。

复现脚本使用固定渲染器，输出文件采用排他创建，避免覆盖已有图形。没有执行模型生成代码，没有安装新依赖或调用外部模型。原折线图和柱状图保持原有变换语义。

验证范围：实际空间坐标、旋转只改变投影、按轴归一化与常数轴、范围及映射拒绝、SVG标签转义、脚本实际复现及拒绝覆盖、API导出和相机参数校验。结果为12项通过（包含原有3项可视化回归）；JavaScript语法检查通过。浏览器整合验收另行记录。

源代码在现有工程内增量修改；新增 radar.py、test_radar.py 与本记录。日期化规划、既有PDF和旧验证产物均保留。
