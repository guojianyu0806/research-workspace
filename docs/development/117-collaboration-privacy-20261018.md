# 跨用户协同推荐与隔离边界

在原有个人推荐之上增加本机、主动加入的协同重排。账号默认不加入，本机默认空间不参与；接口依据当前登录身份绑定工作空间，不接受客户端指定其他用户。加入后投影当前账号最近至多500篇已验证公开arXiv论文的标识和喜欢/不喜欢反馈，同一论文版本按最新反馈合并，清除反馈会移除对应信号。

协同库仅有参与账号UUID、投影摘要及公开论文标识/反馈，不读取其他工作空间的文献库、检索缓存、全文、订阅、笔记或任务。候选始终来自调用账号自己的公开元数据缓存；不会复制他人的标题、摘要、下载状态、代码核验结果或文献ID。页面在加入前显示共享范围，可退出并清除共享投影，原有个人反馈保留。此机制不是差分隐私，不保证完全匿名；不向普通接口返回其他账号身份、邻居列表或逐人反馈。

至少2篇共同喜欢的论文形成兴趣关联，至少3个其他参与账号、且同一候选至少3个同向反馈，才允许受限加减分。使用正向反馈余弦相似度与共同项收缩，调整上限0.75；本人明确反馈优先，样本不足或协同库暂不可用时保留个人推荐。先对完整有界候选池重排，再截取展示列表，避免第100条之后的候选被预先排除。最多500个参与账号、100个邻居，个人投影最多500篇；不进行外部联网或模型调用。

退出及同步在共享库写事务内检查当前参与状态，防止在途反馈在退出后重新发布。群体计算使用同一只读事务快照。协同同步失败不抹除已保存的个人反馈，返回明确待同步状态；推荐读取失败则退回当前账号个人结果。

阶段验证：63项相关测试通过，47.93秒，`artifacts/collaboration-privacy-final-20261018.xml`。随后完善方法说明，专项补测另存。17项真实回环HTTP与当前UI验证通过，`artifacts/collaboration/2026-10-18T15-28-08-402Z/`：5个合成账号，验证主动加入、排序变化、退出、阈值退回、本人负反馈、刷新持久性、默认空间拒绝加入、其他账号访问私有文献/任务/导出404，以及窄窗口、无脚本错误/外部浏览器请求。原文与任务内容摘要不变，模型调用为0；共享字段与内容检查均通过。

前两次局部测试分别因夹具复用查询缓存、未按检索上限分批准备元数据而失败，已修正夹具，失败JUnit保留。第一次浏览器实验的快照把新增空表当作内容变化，已统一空表视图，并修正夹具启动顺序及最终断言的落盘方式；未通过实验不计入成功。

本阶段尚待全量回归及最终服务重载。不调用Pro，不部署公网，不制作或提交参赛材料；源码直接维护，旧PDF、旧文档及旧产物保留。
