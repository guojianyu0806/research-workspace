# 研究任务与独立工作空间

日期：2026年10月8日。

本阶段将问答、比较、逐块翻译、综述、未来方向与论文框架接入持久任务队列，统一暴露文献版本、引用结构、发现订阅、图谱、CSV与图形接口。任务列表只返回摘要，详细结果和来源按需读取，SSE输出有限大小的进度状态。

翻译每完成一块即保存，再让出执行机会。取消在后续调用前生效，已返回的模型结果仍保存；重试复用成功检查点。服务异常中断的在途模型调用标为interrupted，不自动重放，因为服务端是否完成及是否计费可能未知。明确重试后继续未保存的部分。

账号使用scrypt密码摘要、随机会话令牌和独立数据目录。文献、数据集、研究任务和发现偏好按当前空间读取，退出登录返回本机默认空间。该功能用于本机工作空间区分，服务仍绑定127.0.0.1，尚未完成公网部署及安全验收。

默认空间可在页面中临时配置DeepSeek。接口地址与可选模型依据2026年10月8日查阅的[官方文档](https://api-docs.deepseek.com/)填写。密钥不写入文件或返回响应，配置仅保存在当前进程及研究工作进程的环境中；重启主服务后需重新配置。保存设置不发起模型调用。同步配置回调与研究入队共用临界区，防止更换配置时插入任务。

已完成的离线验证包含跨账号资源隔离、持久进度、取消与返回同时发生、恢复后的显式重试、精确原文片段翻译、CSV真实值输出，以及密钥异常响应脱敏。集成前完整测试为145项通过；随后并发修复的验证另在最终工作台记录中列出。模拟模型响应仅用于协议和状态测试，不作为模型质量验收证据。

边界：账户文档解析和各空间研究任务共用一个活动进程，长PDF解析可能使其他空间等待；默认空间解析由单独进程处理。进程没有自动故障拉起，健康检查分别报告两个工作进程的存活状态。SSE是任务状态流，不是大模型逐token回答流。
