一、功能与行为
1. 文献管理的文字块提交翻译后，研究任务页显示“返回文字核对”；返回恢复原文献、页码、文本块 DOM、选区、焦点、换行选项与阅读位置。
2. 从翻译结果点击“查看出处”进入阅读器，显示“返回翻译结果”；返回恢复同一任务的双语结果及阅读段落。其他研究任务的出处使用“返回任务结果”。
3. 支持文字核对 → 翻译结果 → 原文 → 翻译结果 → 文字核对的两层往返。点击顶层模块导航时清理原链及保留控制器；返回上下文仅在当前页面会话有效，不是跨刷新历史。
4. shell 保留原控制器和 DOM，并恢复主容器及普通内部滚动。双语组件独立暂停尺寸观察和动画帧，返回时按文本块与块内位置恢复；窗口宽度发生变化也保持同一段落，不用旧像素位置覆盖新布局。
5. 隐藏的研究任务暂停轮询，使在途读取失效；返回后对进行中任务续接状态读取，对已完成译文直接恢复。普通返回不会重复创建翻译任务。
6. 翻译创建成功后按响应中的任务 ID 精确打开结果，不依赖任务列表排序；用户等待时主动离开模块，迟到的成功响应不抢占当前导航。翻译成功时不在已隐藏的管理页插入顶部提示，避免返回位置下移。
7. 更新 shell.css、shell.js、manage.js、research.js、bilingual.js 的资源版本为 20261013-translation-return1。共享导航外框保持原样；任务来源返回栏仅在存在来源上下文时显示。
